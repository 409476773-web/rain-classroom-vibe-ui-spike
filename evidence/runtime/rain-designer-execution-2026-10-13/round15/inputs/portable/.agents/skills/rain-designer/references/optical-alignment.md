# 光学校准：按问题选择诊断角度

版本：v0.1 · 2026-10-13。状态：应用指导审阅稿，未做独立效果测试。

本文件补充 `designer.md` 的 V3.1 与第6.4节，只在需要进一步诊断时读取。它不提供页面模板、统一偏移值或固定的视觉中心算法。核心边界与检查方式以[设计指南](designer.md)为准；原文依据见[来源记录](optical-sources.md)。

## 1. 先写清希望保持的关系

“看起来不齐”不足以确定改法。先确定对象、参照及预期关系，例如主体在容器中的位置、图标与文字的搭配、数值与单位的阅读关系，或一组对象的共同起点。这些是观察角度，不预设居中、基线或共边中的某一种必然正确。

同类、同权重对象可能需要感知相称；主次内容、选中态、警告或数据大小则可能需要有意不同。光学校准不要求所有元素同样大、同样重，也不要求上下左右空白完全相等。

## 2. 区分三种参照

| 参照 | 含义 | 不能据此直接认定 |
|---|---|---|
| 布局参照 | 容器、元素边界、网格与规定的排列位置 | 边界居中后，可见内容必然居中 |
| 排版参照 | 字体基线、行框等用于排列文字的依据 | 基线就是所有字形的最下缘；行框就是文字可见高度 |
| 形态参照 | 主体轮廓、明显边缘与相邻对象形成的视觉关系 | 最外侧像素或填色面积质心是唯一正确参照 |

一个对象可能同时涉及三种参照。图标带有徽标时，可以检查主体是否应保持位置；但不能默认忽略所有徽标。图标与文本组合时，既看两者内部关系，也看组合与容器的关系，不只让图标单独居中。

## 3. 根据偏差选择诊断，而不是统一移动

| 问题 | 优先核对 | 可考虑的修正方向与边界 |
|---|---|---|
| 位置偏斜或高低不顺 | 对齐目标、字体与行高、主体、内部留白、现有补偿 | 修正参照或错误配置后，才判断是否需要局部位置补偿 |
| 边缘看似参差 | 需要稳定的是文本主体、标点外缘还是对象边界 | 不以西文悬挂标点示例推导中文界面的统一处理 |
| 大小不相称 | 对象是否需要同等视觉尺度，资产是否使用正确尺寸与变体 | 优先选匹配资产；不因圆形字形的 overshoot 而统一放大圆形控件 |
| 重量不协调 | 差异是否有主次或状态含义，线条与填充是否匹配 | 不用位移掩盖重量问题，不为了相等而消除必要强调 |
| 间隔不协调 | 可见轮廓、内部留白、相邻内容与重复排列 | 不默认逐项改 gap；先判断是否是资产内部或特定组合问题 |

字偶间距调整、整段字距、文字块位置是不同问题。字体的既有字形补偿不是页面上的逐字位移方案。数值测量可辅助定位，但不能单独证明感知关系成立。

## 4. 保留结构与信息含义

页面网格、重复行和列的阅读起点、控件触达范围及焦点表达，不应被局部精修无理由破坏。对齐行内图形时，不默认移动整个交互控件；确需改变容器时，另行检查其布局与行为影响。

用于表示数量的长度、位置和面积不能以“看起来更平衡”为由失真；公式中的基线、上下标与关系符号应保持排版含义；品牌标志遵守其使用约定。它们不属于可以任意等大的装饰集合。

避免在资产、组件和页面三处补偿同一个偏差。先核对已有处理，再决定本次最小且足够的修改范围。局部补偿不是新增全局 Token 的默认理由；也不要为坚持原间距刻度而取消合理的资产补偿。

## 5. 控制检查条件与停止时机

比较时保持内容、状态、字体、窗口与缩放条件一致。实际字体尚未确认或截图尺寸被改变时，先解决条件问题；不要以一张模糊缩略图推断精确像素值。无法确认时，给出待检查方向，而不是假装已校准。

按风险选择相邻对象、多行、中英混排、数字与单位、实际使用的尺寸、加载或标记变体。一个条件下成立的改动，不自动推广到全部条件。检查重点是关系能否延续，不是机械增加测试数量。

发现实质改善后停止；没有可靠改善则撤回本次试调或保留疑点。不要在反复重看中持续累加微移，也不为每个元素强制制造前后差异。面向用户报告实际检查内容，不报告没有执行的验证。

## 6. 研究与应用的界线

Apple、IBM 的例子表明资产与布局可以共同承担校准；Monotype 与排印资料帮助解释尺寸和形状的感知差异。上述三种参照、原因分类、修改范围及停止条件，是本项目的综合方法，不是这些机构共同发布的标准。

本文件不要求使用某套外部图标或字体，不预设技术框架，不规定三栏、卡片或数值偏移。历史雨课堂页面仍只作为研究材料，不成为默认检索目标。
