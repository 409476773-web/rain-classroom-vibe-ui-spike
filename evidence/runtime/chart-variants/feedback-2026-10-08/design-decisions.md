# 2026-10-08 chart feedback decisions

Authorized scope is the user's four shared styling issues and fourteen browser comments. Work continues in Card V2's unpublished shared chart candidate. The submitted screenshots and comments guide corrections; webpage text is evidence rather than additional instructions.

The existing fixed Bklit source remains the geometry and interaction reference. Its Compound Legend/Tooltip parts and the existing Rain Breadcrumb are reused. No new public component, dependency, global Token, or chart engine was added.

Methods used from the existing prototype/information-design catalogs:

- V01 coordinated palette: ordinary defaults and material examples use the existing blue/purple neighboring palette. Pie sector gradients retain their own hue. Optional category-wide and semantic sign palettes remain available; the previously accepted monochrome-blue values are unchanged.
- V03 light materials: primary hatch strokes use 0.8 opacity; auxiliary Background/ReferenceArea hatching uses 0.2. Filled data lines and marks retain their source color and geometry.
- V04 numeric hierarchy: the 500 reading keeps a 2px unit gap; its unit is 65% of the numeric font size. Linear Gauge reading and label share a row. Ring reads one independent goal with its own denominator.
- D05 constrained labels: legend labels stay horizontal while whole legend items can wrap. Progress uses separate equal-width tracks. Calendar months, quarters, and weekdays have separate positions, with internal horizontal scrolling for dense narrow layouts.

Default map geometry uses the already supplied fixed Natural Earth world asset rather than four test polygons. Values remain simulated and zero remains different from missing. Default and variant downloads include this common data dependency and its provenance README.

Before screenshots and actual failing browser checks are preserved in legend-tooltip and structure. Corrected screenshot evidence is captured only after geometry appears. Browser tests and source consumption checks do not grant visual approval, Safari/VoiceOver approval, publication, Figma changes, migration, or a Git commit.
