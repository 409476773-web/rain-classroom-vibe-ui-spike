# G5 独立审阅与修正

审阅对象是当前本地候选，三批源码由独立代理交叉检查；主代理另做整合、构建产物和截图检查。人眼接受、对比度接受、发布与生产采用保持分开。

## 复用与接入

- Label / Field 沿 FormItem 和控件自有标签；没有第二套字段上下文或同义公开组件。Input Group 沿原 Input 系列与 Textarea 上下附加区，组合合同不增加独立 UI 资产。
- NativeSelect 保留原生 select、option / optgroup、表单与 ref，采用既有字段外框。Textarea 保留单一 textarea、原生 rows / maxLength / name / form / resize；附加动作区的只读和禁用分别验证。
- Combobox 复用 Rain Input、选项工具、菜单与浮层主题桥；Base UI 拥有唯一交互生命周期。Slider 复用 Base UI 操作与提交，端点不交换身份。
- Calendar 使用匹配的 DayPicker 引擎与动画清理链，年月、导航、日期按钮和时分采用 Rain 部件；内部字段身份隔离。DatePicker 的四种模式均使用确认草稿。

## 发现并修正

1. Combobox / Slider 在首次整合浏览器检查中缺少样式导入。已增加各自组件的局部导入，并复查真实宽度、轨道、滑块、颜色和过渡。
2. Combobox 重试按钮移除后丢失焦点。已恢复至输入框并补回归测试；实际键盘选择与独立重跑通过。[详细审阅](review-b.md)。
3. Calendar 的局部日期按钮数字未继承选中状态前景。只修改该局部 Recipe 的 label 部件，选中数字使用白色，浏览器断言通过；没有改共享 Button。
4. DatePicker 的无效 Date、未完成时分后重选日期及外框状态缺项已修正，并加入关键边界测试。
5. 新 Manifest 的自动验证状态用词与索引约定不符，导致空检索。已改为 `scoped-passed`，五项新资产逐一验证真实命中。日期合同删去不存在的 `name / form`，提交由宿主负责。
6. 独立源码包原来使用通配导出，额外暴露内部上下文。改为从真实公开入口提取完整导出声明，保留多行类型导出；隔离类型检查与构建通过。
7. 嵌套年份菜单检查曾在菜单展开前发送 Escape。Base UI 在下一动画帧打开 Select；验证改为等待展开和可见状态，关闭后等待焦点返回。独立窄屏 Dialog / Sheet 共 10 次通过；没有为该测试时序改动共享 Select 或增加关闭延迟。

## 证明与交付

G4 原接受记录、来源记录与确认文件保持原字节。G5 的有限来源绑定检查当前源码、不可变启动基线与受保护源，再将指定历史哈希接回原证明链；不转移以前的 Gate 或发布权限。篡改授权、旧 Gate、当前源码和前态快照的负例分别检查。

独立源码消费复制选中 Registry 资产与实际本地导入闭包，在仓库外的临时目录检查依赖、类型和构建模块全部位于隔离宿主内。包内公开入口沿真实 API；没有复制完整 UI TypeScript 树。此验证使用已安装依赖缓存，未验证清洁联网安装。

浏览器使用 Chromium、1440px 与 390px。截图已检查浅深主题、双密度、选中日期、窄屏时分与可达底部操作、实际候选浮层及独立源码消费页面。主浏览器报告、日期报告、源码包与当前快照见[验证汇总](verification.md)。

实体中文 IME、Safari / VoiceOver、触屏、完整 forced-colors 和生产性能未审阅；自动检查与代理截图检查不授予人眼接受或对比度接受。
