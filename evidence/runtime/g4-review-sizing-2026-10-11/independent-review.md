# G4 字号与图标修正独立审阅

审阅范围是 2026-10-11 用户反馈对应的 Typography 源合同、试用页、G4 展示与复制代码、五处文档标题 CSS、直接调用、生成入口和有限后继治理。未修改实现、旧记录或 Gate，未重复执行构建和浏览器测试。

源码审阅结论：没有尚未修复的阻塞发现。发现并关闭了两处实际问题：

1. 四个 Input、Select、InputNumber、Tag 的 H1 不能仅删除旧 24/32 覆盖。预设是 Tailwind 分层 utility，未分层的全局 `h1` 会压过它。当前四处保留精确的 16/24 Token；实施计划与精确 CSS 后继校验已同步。首轮浏览器确实记录了桌面 68/71.4、窄屏 36/37.8 的错误，修复后结果由最终浏览器轮次单独确认。
2. 复制的导航代码最初使用了不存在的 `text-rain-icon-neutral-3`。即使仅换成正式 utility 放在图标上，也会被未分层 `.rain-icon { color:inherit }` 覆盖。当前正式 `text-rain-category-icon-neutral-3` 放在 ItemMedia 宿主，正式 ArrowRightIcon 继承颜色，与实际预览的宿主设色一致。该类存在于生成主题与静态类目录。

其他检查结果：

- 两种命名 Heading 预设默认 16/24，仅允许显式 17/18 例外；Data 默认 28/36/700，共享组合校验拒绝 32/36/40。未删除 19 档原子字号，也未限制 UI/Reading 的原子实验或浏览器缩放。
- TypographyPanel 复用现有 resolver 筛选用途选项，保留字号与行高联动、Equal、恢复方案及单位分离；有对应新增失败优先用例。
- 文件图形使用正式 Icon/Size/20，40×40 底块及原颜色保持。导航使用现有冻结的线形 `arrow-right` SVG，没有重画资产；实际预览和复制代码均使用宿主设色。
- 阅读与下载原有同尺寸方案、原生导航、Dialog、下载、已读和 Progress 状态行为未在本轮改动。
- 新链保留实际 81 份原件、34 项有限当前源、48 项保留记录；对旧 phase/Gate/Manifest 能力及原子 Token 仍有严格校验和篡改拒绝用例。箭头新颜色条目仍登记为 meaningful-icon / critical，两主题测量没有降低检查标准。既存全局失败未改成通过。

最终补充审阅：复制代码颜色检查只在精确的 G4 TSX 路径与本轮 sizing 授权下生效。它要求静态 `itemLinkCode` 模板中正式 ArrowRight 导入、唯一的正式 ItemMedia 宿主片段，拒绝模板插值，然后只遮蔽该模板中的一个文字 class；实际 JSX 的颜色扫描继续执行。错颜色、颜色移到 ArrowRightIcon、额外真实 JSX paint 三种反向用例均保持拒绝。未发现泛化颜色豁免或实际 paint 逃逸。

更新最终绑定后，独立直接重读三条链均通过：本轮 sizing 为 34 项源与 48 项保留记录，上一轮 visual 为 18/7，原 G4 为 38/10；实际 81 份本轮 before 原件与原 G4 的 58 份 before 校验仍保留。此前四个标题新 SHA 造成的过期绑定已关闭。最终 20 项 G4 与 4 项 Token 浏览器检查由执行代理完成，独立审阅未重复运行。

用户视觉判断、完整跨浏览器与辅助技术检查、全库回归、发布和业务采用未由本次独立源码审阅确认。
