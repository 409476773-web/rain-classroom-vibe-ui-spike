# Slider 体验改进设计说明

日期：2026-10-13。授权来源：用户在当前页面、交互和成熟组件对照审查后明确指示“开始实施”。工作模式为 System Mode，沿用已有 `sliderRefinement` 共享候选授权；本记录不授予验收或发布。

## 保留的基线

静止已选轨道与滑钮外圈继续使用已登记 `Fill/Brand/Solid/2` / 55% Alpha，悬停、聚焦或拖动时同步增强为同一不透明 Token；表面色内芯无中心点。滑钮 default 16px / compact 12px、轨道 4px，区域 Density、扩大命中区、键盘焦点、强制颜色与减少动态效果保持。用户之前认可的颜色不扩展为对比度接受。

## 本轮判断与实施范围

| 发现 | 处理 | 所属层 |
| --- | --- | --- |
| 刻度脱离轨道 | 让刻度靠近可见轨道定位，命中区独立扩展，保留 edge 坐标对齐 | 共享 Slider CSS |
| 固定 60 与当前及格线混淆 | 固定参照标为“默认 60”，当前值由有效状态派生 | 页面组合 |
| 窄容器标题仍显示旧值 | 常驻读数直接使用当前值 | 页面组合 |
| 范围重合后向左拖动受限 | 实现并验证必要的重合端点选择，保留固定身份及 Base UI 拖动链 | 共享 Slider |
| 可见范围提示带“滑钮”辅助名称 | 可见提示用“下限 / 上限”；`thumbLabels` 保留独立辅助名称 | 共享 Slider |
| 输入冲突和再次编辑的结果含义不清 | 保留非法草稿和最后有效值，分别表达未应用、待保存、预览、已应用 | 页面组合 |
| 范围两个输入关系松散 | 组织紧凑的下限—上限字段组，错误反馈使用稳定区域 | 页面组合 |
| 音量、倍速外围空间过大 | 同一参数面板中采用紧凑参数行 | 页面组合 |
| 边界加载打断主要任务 | 收进“状态与边界”，外观对照后移 | Components 展示页 |

设计依据沿用 Rain Designer v0.2.1 / 指南 v0.5 的 V05、D01、D02、D05、I01：状态含义一致、围绕一次调节任务组织、输入与反馈就近、容器变化保持关系、区分草稿与业务生效。实际视觉与交互检查由本轮当前页面证据记录；文档不代替实测。

## 重合端点与输入合同

共享实现沿用 Base UI 的端点引擎。常规碰撞保持 `none`；只有直接从完全重合滑钮开始的指针操作临时使用其现有 `swap` 行为，首次接受的不相等变化后恢复 `none` 并固定本次端点。向左展开下限、向右展开上限，不取决于重合时命中了哪个滑钮。取消的变更保留方向选择机会，原生变更和操作结束回调保留，指针或触控取消/结束后清理临时状态。轨道点击、非重合操作、固定 Tab 顺序与独立辅助名称保持。

范围可见提示固定使用“下限 / 上限”与 `formatValue`，完整 `thumbLabels` 继续提供辅助名称；没有新增公开属性。精确行为已与当前共享源码核对，自动与真实浏览器的结果仍由根任务单独记录。

数值输入继续复用 InputNumber，number/null 草稿、有效值和业务结果由宿主分别拥有。空、越界、小数步长或跨端冲突不静默修改；单端输入结束不提交另一端的未完成草稿。恢复默认需显示恢复后的值，并遵循各组合现有即时应用或显式保存合同。

## 实施后复核

刻度距可见轨道下缘为 4px，default / compact 和仿真粗指针下保持；扩大命中区不参与视觉间距。音量与倍速共用列轴，窄屏改为标签与读数在上、轨道占整行。数值输入复用既有 `controls={false}`，保留键盘编辑及共享错误校验，避免在这组调节组合中增加重复的步进停靠点。

范围组合只同步本次活动端草稿；另一端为空、越界、未完成或冲突时保留原文，结束操作不提交整组。自身滑钮仍可修复该端草稿。原生数值错误和组合错误占稳定区域；针对 InputNumber 的内联尺寸隔离，只在本页精确输入错误区域解除其限制，避免文字收缩到零宽。两项独立审查发现均补充回归并复验关闭。

当前运行、真实页面截图和检查边界见 [本轮验证](verification.md)，独立审查见 [审查记录](independent-review.md)。颜色保留原两处 Solid/2 + 55% Alpha；静止外圈仍低于已登记 3:1 门槛，未授予对比度接受。
