# 预先固定的消费需求

固定时间：2026-09-16，消费实现开始前。此需求不指定组件、排版尺寸或页面组织方式。

教师需要在“设计方法与实践”课程中编辑一次研讨活动。初始活动名为“用户访谈研讨”，类型可为课堂研讨、案例复盘、作品评议；需要填写地点、活动说明和讨论提纲。名称、类型、地点和活动说明必填；提纲可选。活动说明与提纲可能包含多段长文字。

活动可以不限制报名人数，也可以设置 1–200 人的整数上限。关闭人数限制后不应被隐藏的无效值阻止保存，再打开时保留本轮输入。

教师能看到已保存的活动，编辑中的输入不应提前改变已保存内容；校验失败应帮助定位问题。未保存退出要保护草稿；保存失败可重试并保留内容；保存中防止重复提交；保存成功更新活动信息。需要可重现的本地保存失败演示。

页面在桌面及手机宽度均可使用，键盘能完成主要流程。本地原型使用虚构信息、只在内存保存，不连接真实服务；不需要附件、封面、分步流程或后台权限系统。

## 消费执行约束

只提供新导出的 Starter 和上述业务需求；不提供本轮聊天、其他项目历史或指定组件答案。先读取导出目录的 AGENTS.md。共享包和锁文件只读，新增页面限制在导出目录；不得提交/发布。

在第一次可运行时保留源码快照及桌面、窄屏截图，再进行自查修订；记录实际读取的材料、设计选择和每次修正。至少保留一个能检查真实状态/校验行为的可运行检查。最后用 pnpm typecheck / pnpm build 和实际浏览器验证。

身份：无本轮聊天历史的单次消费试验。不是对照实验或用户视觉接受；不能推导质量提升比例。实施者仍拥有通用模型能力及提供的参考源码，不能称为从零能力测试。
