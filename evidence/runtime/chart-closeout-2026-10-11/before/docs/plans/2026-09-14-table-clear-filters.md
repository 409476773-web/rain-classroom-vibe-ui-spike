# 资料表格：一键清空筛选

用户要求：查询或选择筛选后显示“清空筛选”文字按钮，配图标库现有面状圆圈叉。Prototype Mode，仅调整本地资料表格配方，复用 Button text 与清空状态函数。

- 由已生效的 columnFilters 派生显示条件；仅输入未提交、空关键词、全部状态不算生效筛选。不增加单独显隐状态。
- 文字按钮位于状态筛选之后、视图切换之前，与控件垂直居中；尺寸随既有密度选择 regular/compact。使用已可用的 CircleCloseFilledIcon（icon/circle-close-filled，源节点63:88），静态单图标入口、颜色由文字按钮继承。
- 一键清空搜索草稿和所有筛选，回第一页，重置选择和旧提示，焦点回搜索框；保留排序、每页容量、视图和列配置。复用现有清空函数。
- 无结果时同样使用筛选栏入口，取消重复的空态“清空筛选”按钮；无资料时的添加示例入口保留。
- 修改范围：本地recipe、现有单元/浏览器验证以及本记录。公共组件、Token、图标源和既有视觉接受状态不改。

验证：先通过一个行为用例验证显示/隐藏、联合筛选和完整重置；现有Table流程回归。浏览器复核实心图标加载、文字按钮、同排居中、两种密度/主题、320px以及无结果/加载禁用。运行受影响类型和治理检查；未验证项如实记录。

实施完成。4/4资料配方单元、三浏览器Table15场景（初批12项＋修正图标URL断言后的3项）、类型、prototype构建与完整治理通过。证据与分批结果见 [验证记录](../../evidence/runtime/table-clear-filters/verification.md)；新按钮视觉待用户验收。
