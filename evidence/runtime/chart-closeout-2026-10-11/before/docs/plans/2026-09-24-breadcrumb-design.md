## 项目身份与交互状态

当前位置属于项目身份，与悬停、按下、焦点及菜单展开分别表达。

| 身份或状态 | 规则 |
| --- | --- |
| 可跳转上级 | 点击进入该层；提供默认、悬停、按下及键盘焦点 |
| 当前页 `current` | 无同级菜单时静态；有同级菜单时整项为菜单按钮，保留当前位置语义 |
| 普通层级名称 | 用于没有独立页面的分组；保持正常可读性，不提供点击反馈 |
| 真正禁用项 | 仅用于确实不可用的入口，明确阻止操作，不只改变颜色 |
| 可下拉项 | 文字与箭头统一触发同级菜单；整项共用热区、焦点和展开状态 |

原面包屑单项的 `selected` 更名为 `current`；菜单内部的当前分支标记单独保留。当前页若提供同级切换，其文字保持静态，箭头仍可操作。

## 可下拉项的整项触发 · 最新确认

2026-09-24 用户在运行预览后提供两张截图，明确要求“整个面包屑都可以下拉与收起”，Hover 为文字与箭头共同覆盖的完整浅蓝圆角底。此指令覆盖早先的“文字返回该层、箭头展开菜单”决策。

- 有同级选项的面包屑项是一个完整菜单按钮，点击文字或箭头均展开/收起同一菜单。
- Hover、Pressed、Focus 和 Open 状态覆盖整项，箭头只是按钮内的装饰图标，不是独立 IconButton。
- Tab 只进入整项一次；菜单支持方向键/Enter，Esc 关闭后恢复整项焦点。
- 返回该层通过菜单中的对应目标完成；无同级菜单的普通上级仍是链接。
- 当前页若可切换同级，整项可操作，并在按钮上标记 aria-current；无同级菜单时保持静态当前页。
- 菜单展开期间抑制完整名称 Tooltip；关闭后仍可通过整项聚焦或悬停查看实际截断的名称。
- 菜单保留当前分支标记；无可切换目标时隐藏下拉能力。

同级切换后的有效路径由宿主提供。例如从“消息中心 / 行政通知 / 详情”切到“消息”时，进入其对应页面并重建路径，不把旧的“详情”自动接在新分支后面。

## 长名称、深路径与窄容器

- 名称按实际可用宽度截断；仅实际截断时提供完整名称提示，鼠标与键盘均有查看完整名称的方式。
- 多项同时过长时，优先为当前页与直接上级保留可识别的内容。
- 层级过多时将中间祖先收进独立的 `…` 菜单，优先保留首级、直接上级与当前页；重合的层级只显示一次。
- `…` 展示被隐藏的祖先路径；单项下拉箭头展示同级选项。二者复用菜单能力，内容含义分开。
- 窄容器优先折叠中间层级，保持单行，不通过缩小字号维持布局；进一步收缩时仍须保留当前位置与可用的上级入口。
- 路径反映页面层级；浏览器历史返回由外部返回按钮承担。

折叠示例：`教学空间 / 我的课程 / 高等数学 / 作业管理 / 第三次作业` → `教学空间 / … / 作业管理 / 第三次作业`。
