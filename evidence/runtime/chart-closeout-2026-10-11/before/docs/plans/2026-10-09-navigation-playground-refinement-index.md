## 3. 共同视觉与语义边界

- 雨课堂品牌蓝、PingFang SC 字体、语义颜色、Focus、表单组件和现有图标继续是依据。生成图只表达层级与组成，不是新 Token 或像素尺寸的事实源。
- 白色任务面与浅冷色导航区服务于当前任务；避免层层套卡、过多蓝色和用装饰动效抢内容。深色必须检查导航文字、图标、当前态和 Portal 本身，不能只把外层背景变暗。
- 默认态、hover、pressed、selected、focus 及组合态保持可辨；selected 与 focus 是不同状态，不能仅靠移除 focus 来接近静态图。
- Tabs 切真实内容面，Bar／List 进入目的地，ObjectNavigator 选择对象，ScopeNavigation 改范围，SegmentedControl 选互斥条件，ConnectedSurface 绘制关系，Workspace 分配可恢复区域。相似外观不合并语义。
- 局部推荐场景的内容、宽度和几何不升级为全库默认；未提交、缺测、失效、加载和错误按业务事实显示，不强行统一为 disabled。
- 草稿按内容身份保存；切换外观、遍历轴、区域显隐、窗口宽度不等于保存，不重新分配成绩或清空编辑。

三项不可按旧稿实施：活动卡片使用横向条而非完成环；窄 Workspace 使用最后的覆盖修订稿；收起导航需要补静态图漏画的明确展开按钮。各细节以对应计划中的最终口径为准。

## 7. 实施前共同约定

### 7.1 每一层只承担自己的工作

| 位置 | 负责 | 复用方式 |
| --- | --- | --- |
| 公共 UI／Layout | 选择语义、键盘、受控状态、面板生命周期、区域恢复 | 继续消费现有实现；只有被证据确认的公共缺陷才修改共享层 |
| 局部视觉配方 | 条目排版、状态外观、局部主题映射、必要装饰动效 | 独立页和指定建设样例引用同一份；不各写一套近似样式 |
| 小场景宿主 | 模拟数据、当前对象、草稿、路由适配、本地操作结果 | 按真实使用拆分状态；不创建统一业务数据层或通用场景引擎 |
| 文档展示 | 场景顺序、解释、预览设置、高级状态、代码与建设页入口 | 继续使用已有 ComponentDoc／DocExample；页面内容不成为新的公共导航包装器 |

首屏顺序为用途说明、推荐场景和对应建设入口；其后为必要高级状态、使用边界、API 与代码。ObjectNavigator 的三个用途分别成例；Scope 的同一组数据在两页分别说明范围选择和连续表面。控件名称、读取状态和调试编号不占据业务工作面。

代码要对应用户看到的效果：已有 DocExample 支持独立 code，推荐例给出实际局部配方调用及必需的样式／数据依赖；文档底部保留公共组件的最小调用。明确局部外观需要的文件，不能只展示裸公共组件代码却暗示复制后自动得到精修外观。沿用现有复制入口，不为此增加下载系统。

### 7.2 宽度、地址与焦点的统一口径

- **宽度**：同时记录浏览器视口与示例实际内容宽度。现有文档最大 1080px，经文档和预览内衬后最多约 966px；390px 视口在场景自身内衬之前最多约 324px。这些为源码尺寸推算，最终用浏览器测量。活动列数、Scope 窄宽和 Workspace 恢复均以实际容器为准。
- **活动卡片**：两行是常规宽度目标；三列只在内容容纳时成立。保留迷你条、完整读数和可读字体，先降列数，仍不足或文字放大时允许增行。不能以压短条形、裁切文字或放大整个文档壳来强凑三列。
- **目的地**：NavigationList 与 NavigationBar 同样验证点击、刷新、深链接、后退／前进。App 已有 hashchange 更新，推荐值从合法 query 得到；不新增一套路由。原生修饰键和新标签页保留。
- **焦点**：已定位 App 的 RouteFocus 与 ComponentAssetPage 两处标题聚焦。前一切片统一处理两个示例的同页 query 情况，后续复用；只让同页焦点归小场景，保留跨文档标题聚焦和其他组件页行为。此处只是源码判断，运行表现尚未实测。
- **示例实例**：推荐首屏的 URL 状态、高级示例自由状态和业务草稿各自持有。折叠高级区不清掉已编辑草稿；深色和密度沿用现有文档设置，不增加互相矛盾的第二套开关。

### 7.4 操作与待验证问题

每个可用动作都要有对应结果：选择改变内容，本地保存更新该对象的保存状态，标记反馈在被标记对象上，查看结果进入或展开现有结果区域。保留“添加资料”等动作时提供最小的本地结果；不支持的业务动作明确为演示或禁用说明，不能用看似成功的空提示冒充实际变化。无需因此建设上传、接口或真实课程服务。
