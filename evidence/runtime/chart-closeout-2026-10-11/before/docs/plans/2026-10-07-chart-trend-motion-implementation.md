# 趋势／面积交互与动效改造计划

> 使用 executing-plans 按本计划实施；继续当前会话，复用现有 card-v2 工作树。

**目标：** 将方案v0.5确认的Bklit展示强度、读取联动和选择状态落实到一个完整趋势／面积样本。

**架构：** Prototype Mode / local-experiment。继续用已安装的Plots／G2绘图，读取原生坐标与尺度定位页面私有反馈层；不建立公共Chart接口。沿用Rain字体、色组和P03材质；其他六个绘图实例用于回归。

**技术：** React 19、TypeScript、Plots2.6.8、G2 5.4.8、现有CSS与浏览器动画能力；本轮不新增依赖。

**授权：** 用户在确认v0.5后明确“开始改造”。本地趋势样本、必要测试与记录已获授权；公共资产、Token、Figma、发布、业务迁移和Git保持原边界。

## 1. 基线与失败验证

- 保存本轮源码、方案与阶段起点；重新记录公共资产、其他图体、依赖与锁文件哈希。
- 新建`tests/e2e/chart-trend-motion.spec.ts`和独立配置，以真实指针／键盘行为验证读取、固定、图例及零／缺测。
- 先在旧页面运行，确认新交互接口缺失导致预期失败；再开始实现。
- 新证据只写`evidence/runtime/chart-trend-motion/`，旧浏览器测试仅增加截图目录环境变量，保留首版证据。

## 2. 一个完整趋势样本

- 创建`apps/prototype/src/scenarios/chart-validation/trend-motion.tsx`及局部CSS；`cartesian.tsx`仅移出原趋势实现，柱与迷你图保持原行为。
- 原生曲线与面积约1秒左向右揭示，后续更新连续变化；操作期间以最新状态为准，避免重复开场。
- 同一X身份连接指示线、点环、时间浮标、提示与外部读数。指示灵敏、面板有缓冲，边缘避让；局部亮线及面积渐隐分别核对真实路径。
- 鼠标临时读取、点击固定／另点切换、空白／Esc取消、键盘移动与读数选择；固定优先，离开不丢键盘焦点。
- 图例悬停强调、点击隐藏／恢复且至少保留一个系列；提示和读数仅展示可见系列，更新／配色／缩放保留X。
- 零值有定位点，缺测无伪造点和连线；Reduced Motion即时定位并停用长揭示与缩放缓冲。

## 3. 检查与交付

- 新行为测试和原四项浏览器检查、prototype类型检查、独立入口构建。
- 实际查看默认、连续移动、固定、图例、数据更新、边缘、窄屏与Reduced Motion；截图与短动效证据归本轮。
- 独立审阅原生几何与状态连接；受保护源码哈希复查，未实测内容分别记录。
- 更新方案、局部阶段记录与验证报告；运行／自动检查与用户视觉验收分别记录。

方法：V01保留系列颜色身份；V03校准清晰线与轻面积；V05把外观和行为一起改造；I02让临时读取、固定选择、原始数据保持一致。当前重点是趋势样本，不调整实验页整体布局。

执行结果：本地趋势／面积样本完成；最终新6项＋旧4项Chromium检查、prototype类型检查、独立入口构建通过。实际浏览器检查了固定、更新、图例及390px缩放。点环连续morph的91帧采样全部可见，最大贴线误差约0.023px；退出残影与动画期间非法SVG路径已修复。用户视觉验收待确认，完整证据及边界见[验证记录](../../evidence/runtime/chart-trend-motion/verification.md)。

并行决策：实施期间，另一聊天“推进 Rain Next 验收计划 (2)”将共享方案更新为v0.6，并开始Bklit原生＋Rain主题的独立四样本接入。本任务保留已授权v0.5的G2实验结果作为对照，未改写该方向。原v0.5方案快照见[本轮基线](../../evidence/runtime/chart-trend-motion/before/design-v05.md)。
