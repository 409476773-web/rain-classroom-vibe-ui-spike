# M2 本地体验说明

## 作业批改

当前修订版按 14 条浏览器批注采用试卷按钮组、底板 Tabs、320px 目录、无可见标题的常规搜索/筛选和模块内单一收起图标。目录条目为页面局部 Recipe，并非公共目录组件；详见[修订证据](../../evidence/runtime/generation-quality/bm-c-feedback/review.md)，视觉仍待复审。

本轮追加 13 条批注修订：白色吸顶顶栏与返回分隔线；折叠箭头与返回均使用正式图标，面板收起采用 32px 点击区/16px 图形；白色工具栏保留公共 contained Tabs 的灰色底板。评分状态使用 SystemStatusTag，上一/下一为图标操作，保存为中性次操作，保存并前进为主操作。评语保留可选语义，辅助说明放入标题旁帮助；主题切换放入“演示设置”。详见[本轮证据](../../evidence/runtime/generation-quality/bm-c-composition/review.md)。

打开预览地址的 `/#bm-c`。选择 A/B 卷，用“按题批改”连续切学生，或“按人批改”连续切题。展开目录中的另一组后会定位待批作答，返回已看过的组会恢复位置。

输入 0–本题满分的分数（支持 0.5 分），评语可选。“保存并下一位/题”成功后前进；在“演示设置”勾选下次保存失败，可检查原作答、输入与重试。切换对象、收起目录/评分区或加宽评分区，草稿都会保留。保存期间对象和筛选暂不可切换。

## 学习报告

打开 `/#bm-d`。筛选班级和周期，四个指标始终覆盖全部筛选数据。明细展示全部筛选结果；切换趋势指标、选择固定对照周不改变统计范围。质量改进版的图表随容器缩放，可悬停读数，或聚焦图表后用左右键逐周查看；周次选择器提供固定读数，明细表支持横向滚动。5337 的原 M2 固定样本仍保留旧图表，不能与改进版混称。

本轮在 13 条批注修订版上继续收敛：正文与控件 14px，标题和关键数字 16px；统计口径集中在页头帮助中，趋势帮助只解释图表操作。图表即时提示明确为“临时查看”，周次选择明确为“固定对照”。观察与示例建议共用容器；普通密度的明细一次展示最多 12 条记录。帮助按 Escape 关闭并返回焦点。详见[本轮记录](../../evidence/runtime/generation-quality/composition-refinement/review.md)，效果待人工查看。

“演示设置”可检查加载失败、重试和空数据。教学建议是固定示例，未连接服务。两页均可切换浅色/深色。

## 本次范围

这是独立的本地源代码样例。数据全部虚构，编辑只保留在当前页面，刷新或离开场景后恢复。新视觉仍待人工确认；真实中文输入法、读屏、物理触屏及跨机器字体效果尚未验收。没有发布、业务迁移、Figma 写入或 Git 提交。

源码提供 C/D 页面及本地状态合同；保留既有 A/B 与共享组件。字体只引用本机已有字体，不包含字体文件。RN-16 低频品类按真实场景继续接入。

## 本地复验

需要既有 Node/pnpm 环境和本机依赖缓存。在独立样例根目录执行 `pnpm install --offline --frozen-lockfile --ignore-scripts`、`pnpm typecheck`、`pnpm build`。用 `pnpm dev` 打开终端显示的本地地址后添加上述页面路径。

回退可重新解压本次固定归档。源码锁会检测额外文件、改动文件及符号链接；修改后的副本应另行标记，不能继续冒称同一个固定版本。

### BM-C 主操作辨识修订

当前输入使用 filled 变体；目录待批改为标签、已评分为加粗数据字体；折叠箭头置后对齐；作答与评分共用白色工作面，目录保留白色轻边框。已删除重复卷别摘要与评分对象文案。可在 1259×695、899、390 宽度检查，详见[本轮证据](../../evidence/runtime/generation-quality/bm-c-primary-workflow/review.md)。视觉接受仍待用户判断。

BM-C 目录已补24px学生头像、组间细线与留白、橙棕分数和弱化单位，以及128px短得分输入。头像在按题/按人和筛选间稳定；选中分数跟随蓝色行状态。[本轮证据](../../evidence/runtime/generation-quality/bm-c-directory-detail/review.md)。

按人批改现使用 QuestionNumber 横向题号列表，保留状态/分数和鼠标、键盘切换；筛选后保留原始题号，保存期间禁用。[本轮证据](../../evidence/runtime/generation-quality/bm-c-question-switch/review.md)。
