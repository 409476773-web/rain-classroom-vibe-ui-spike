# 图例与读数规则 · 当前候选

本页落实此前已确定的方向，适用于当前19入口、170来源变体和业务宿主。它不增加隐藏系列、固定Tooltip或跨图联动能力。实际第二批结果与范围以[实施记录](../../evidence/runtime/chart-experience-second-batch-2026-10-11/verification.md)为准；新宿主仍需自己的数据、容器与体验验证。

## 临时聚焦

普通趋势、比较、构成、进度和方向图例用于读取、识别对象，默认保持全部数据参与绘图。

| 事件 | 当前规则 |
| --- | --- |
| 指向某项 | 临时聚焦该对象；其他对象可以减淡，数值、量程和分母不变 |
| Tab聚焦某项 | 与指向读取同一对象，保留可见焦点；不要求鼠标才能获得读数 |
| 点击／Enter／Space | 读取并聚焦当前项，不作为隐藏、选中或开关；临时状态不使用 `aria-pressed` |
| 指针离开 | 清除指向预览；图例内仍有键盘目标时恢复该目标 |
| 焦点离开／Escape／外部点按 | 清除临时聚焦；Escape不删除数据或改变层级 |
| 同对象数值更新 | 保留对象身份和焦点，从同一当前数据读取新值；不因数值变化重挂载图例按钮 |
| 类别删除、筛选或重排 | 幸存对象按身份跟随；对象消失则清除，不能把旧下标解释为另一项 |

当前 `ChartLegend` 与compound `Legend` 的条目以唯一、稳定的 `label` 标识；宿主应保持标签稳定，数值放在 `value`。真实业务有同名对象时，先提供可区分标签，不从数组位置猜身份。`ChartLegend` 无读数回调时保留静态图例；有回调的默认条目为按钮。自定义 `renderItem` 与compound children仍需宿主提供可操作的按钮及清楚名称，Parts不会凭空赋予任意子内容键盘语义。

指向／键盘混用与更新按当前实例隔离。精确表、图上标签与提示读取同一数据；图例聚焦不改变构成总量、堆叠量程、独立目标的分母或正负含义。

## 逐图约定

| 入口 | 图例或等价操作 | 清除与数据变化 |
| --- | --- | --- |
| Line／Area／Composed／Bar／Scatter | 系列按钮临时聚焦；日期和单位仍在提示／表格中读取 | 按上表；原有范围选择、缺测断口与堆叠口径保持 |
| Pie | 类别图例读取完整名称、数量和原总量占比；小扇区也能从图例／表读取 | 类别移除清除目标，重排不换身份；零总量不造比例 |
| Ring | 逐个独立目标读取当前值／目标值；多环不合成一个总进度 | 零目标为“不适用”，超目标保留真实值；不为了画环改写分母或截断表值 |
| Gauge | 展示型读数及精确值；没有系列对象，不增加伪图例 | 0与未提供值分开；非法范围拒绝绘制 |
| Radar | 系列图例临时聚焦；维度分数从同源精确表读取 | 不合计各维分数；密集／长维度不能牺牲完整读数 |
| Matrix | 编码图例说明量级／等级；格内指向及键盘巡读读取行列对象 | 按稳定行列ID重读；0、缺测、不适用分开；Escape清除临时读数 |
| Heatmap | 连续／分级色阶表达区间；逐日键盘读取与提示使用真实日期 | 窄容器把目标滚到可见；更新重读该日，移除才清除；补位不冒充观测，0与缺测分开 |
| Funnel | 阶段图例／常驻标签／精确表读取人数与入口分母 | 保留阶段顺序；缺项不补0，增长不伪造流失率，零入口不生成比例 |
| Sankey | 节点、连线提示和完整流向表；没有系列图例，不增加开关 | 细流量保留真实值，零连接不画成正流量；名称与单位一致 |
| Sunburst | 当前层级图例和按钮可查看下级；面包屑返回 | 临时预览清除与层级动作分开；点击有下级项是导航，不能改成系列隐藏 |
| Choropleth | 世界图的连续色阶与地区精确表；中国宿主提供明确区域选择、下钻与返回 | 世界展示图不占住页面触摸滚动；中国选择／失败恢复保持其私有合同 |
| Network | 指向／键盘为临时预览；点击／Enter固定对象详情 | 固定详情不被其他指向覆盖；Escape／空白／清除解除；目标被筛掉时清除，保留已确认四组范围 |
| ProfitLoss／Candlestick | 正负或方向图例临时聚焦，颜色含义固定 | 不把聚焦当作盈亏符号或涨跌方向改变；精确读数保留 |
| LiveLine | 当前单系列展示与暂停／手动追加控件，无系列切换 | 保持暂停、窗口与时间身份；真实断流／重连属于后续业务接入 |

## 接入与检查

优先使用既有图例Parts和宿主读数，不再为同一图添加一套隐藏状态。需要隐藏系列时必须另行定义业务理由、量程、堆叠、构成分母以及恢复操作；本页的临时聚焦不代表已有这些能力。

检查指向、Tab、点击／Enter／Space、混合输入、Escape、外部点按，以及数值更新、目标删除和重排。用真实完整名称、两档容器与普通／减少动效核对图形、读数与焦点；多实例不能相互影响。真实Safari／VoiceOver、实体触屏和完整对比度仍需独立验证。
