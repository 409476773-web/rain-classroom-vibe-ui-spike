# BM-D 教学报告（RN-12）

身份：`local-experiment`。VE-007 为 AI 分析/摘要分层参考，VE-010 仅使用已登记的脱敏结构审计，不转录教师档案。数据全为新建虚构教学汇总：两班、6 周、每班每周应交 26 份，每条记录包含应交份数、提交份数和总分；每份作业满分 100。

| 指标 | 统计定义 |
| --- | --- |
| 应交作业（份） | 完整筛选集 expected 之和，跨周为作业份数，非去重学生数。 |
| 实际提交（份） | 完整筛选集 submitted 之和，同一学生跨周提交分别计份。 |
| 平均分（分） | scoreTotal 总和 ÷ submitted 总和；按提交份数加权，不对周均分直接求均值。没有提交时显示破折号。 |
| 提交率（%） | submitted 总和 ÷ expected 总和 × 100；分母为零显示破折号。 |

页面拥有数据源、班级/周期筛选和请求状态，先筛选完整数据再聚合。明细最后分页，每页 4 条，不能把分页切片交给 KPI 统计。Loading/Error 时不显示旧指标；失败有聚焦提示及重试，空集有恢复入口。复用可取消模拟任务，同步锁阻止重复请求，卸载取消并忽略迟到结果。

图表只拥有展示指标（平均分/提交率）和选中周，不修改数据源、统计范围或 KPI。周度系列按同一公式独立计算，纵轴固定 0–100。一班实线圆点、二班虚线方点，并提供命名的周按钮、读数区域和分页等价数据表，不依赖颜色区分。数值为坐标而非 CSS 视觉配置。样例不支持缺周数据、不建立通用图表引擎；接入真实数据前应定义缺测断线与服务端验证。

局部配方 `bm-d-learning-report`（`.bm-d`）复用 Grid/Stack/Inline；页面内 Statistic 分离 dt 标签、dd 数值与单位。只有四个 KPI 的关键数字和紧邻百分号使用 Data role，单位和表格/坐标元数据用 UI role。字体只引用本机，不分发文件。系列色为 Icon/Second/1 与 Icon/Green/1，表示两个班级的图形标记，统计公式不依赖色号。AI 区域是明确标记的固定示例，不调用模型也不生成因果结论。

精确颜色用途与 Light/Dark 实测见 M2 颜色证据；新视觉 Human Gate 为 awaiting_human，未授权发布、迁移或字体分发。运行记录见 [M2 验证](../../../../../evidence/runtime/m2/verification.md)。
