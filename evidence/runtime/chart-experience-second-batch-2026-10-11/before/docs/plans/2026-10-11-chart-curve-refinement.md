# 图表曲线观感修复 · 2026-10-11

用户反馈多个曲线有细小转折、观感不佳，并明确授权“确定，开始修复”。此前“绘图精度与显示精度分开，再统一比较曲线效果”的建议已确认；不再次要求实施确认。

本轮按 System Mode 登记，实际优先采用 Playground 局部数据与现有 curve Props。现有共享候选、未发布状态保留；人工视觉验收待用户查看。参考当前运行图及用户组合图截图，方法 V05（现有组件能力调整）和 I02（趋势与精确读数并存）。

## 最小完整范围

- `chart-data.ts`：正常及缺测完成率使用真实比值；人数整数、日期和全部其他数据保留。
- 受影响的默认、正式示例和 MiniTrend 宿主：现有库插值能力做一致性校准；图表中明确展示 Linear / Step 或用户手动选曲线的能力保留。
- 所有完成率 Tooltip、表格等文字格式避免无限小数；显示舍入不得回写绘图值。
- 同步必要测试、当前阶段与任务证据；不新增引擎、公共API、依赖或全局视觉规则。

选项：仅修精度可消除整数比率平台，但不能改善其他计数曲线；改用现有 Natural 可让弧度更连贯，需要逐段检查过冲；Basis 拟合不经过原始点，不适合本轮准确读数目标。优先前两者组合，只在实际数据几何检查通过的宿主使用更连贯的插值。

实施选择：本地 `shared.trendCurve` 仅从现有 Natural / MonotoneX 工厂中选择。当前时序Mock中，缺测、零、相邻平台或首尾斜率骤缓继续用保形曲线；其余通过逐段审计的系列用Natural。1/3首尾斜率条件来自本轮既有数据的具体反例校准，不是任意输入保证，也不成为公共默认。Mini既有profiles和学期/两期/版本三个业务面积样本独立通过Natural校准。显式Linear/Step和已有手动曲线选项保留。散点双轴复用真实比率，同步一位小数的文字格式。
