## Contract

- `Alert`: tone info/success/warning/error (info default); presentation page/banner (page default); plain text defaults to no icon, while compound content defaults to the formal filled tone icon; `icon` can be false or a custom formal icon; optional onClose and closeLabel. No onClose means no close button. Native role/aria-live/ref forwarded; static default has no live-region role.
- `AlertTitle`, `AlertDescription`, `AlertActions` remain open composition. Plain text is also valid. No generated title IDs or context unless needed.
- Close emits a request, never self-unmounts or cancels a request. Alert does not autofocus, set timers or persist state. A close handler must arrange focus if it removes the active element.
- Short-message A uses a named local recipe and icon=false; compact density only reduces spacing. Alert actions use same-family text or mini tertiary Button styling. Actions preserve Button/Link semantics and never inherit a destructive action from an error tone.
- Default typography 14/22; title 600; description reading 14/24. Page radius6, line1; default single-line padding4/16, compact4/12; content-rich alerts14px block padding; icon16, close24/14. No fixed height. Natural long-word wrapping, first-line icon alignment, container-responsive actions. Banner has zero radius and bottom border, never owns sticky placement.
