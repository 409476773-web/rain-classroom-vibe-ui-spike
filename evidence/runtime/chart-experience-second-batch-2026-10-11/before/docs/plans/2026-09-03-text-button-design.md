## 1. 先看结论与当前状态

文字按钮是一种轻量操作：平时没有底色和边框，鼠标移上去后才出现浅底。普通操作默认灰蓝，需要突出时用主题蓝，有真实风险的操作用危险红。**不提供警告橙，也不把它列为“以后再做”。**

跳转页面的文字与执行操作的文字分别处理：链接默认主题蓝，悬停只加深文字、不铺底；独立入口不加下划线，夹在正文里的链接保留细下划线。

输入框内已经设置的文字操作默认常驻。暂不可用时变淡，但保留位置。它不是清除叉号，清除叉号的规则留到 Input 单独讨论。

## 2. 已经确认的设计规则

### TB-01 · 设计上称为文字按钮，实现上不再建立重复组件

- “编辑”“重试”“打开弹窗”等即时操作，归入 Button 的最低强调文字样式。
- “查看详情”“使用帮助”等真实跳转，使用 Link，也就是浏览器能够识别的真正链接。
- 两者可以共用部分外观，但不能把跳转做成只会响应点击的普通按钮。
- TextButton 仍可作为设计讨论与示例的名称；不另建一套与 Button、Link 重叠的公共使用方式。
- 一个文字控件只有一个点击目标；不能把左右图标拆成两个操作。
- 只有图标、没有可见文字的操作属于 IconButton，不混入本稿。
- 文字按钮不代替操作区内唯一的主要提交按钮。

这里继承的是已经接受的复用审核决定，不重新开启组件身份投票。依据见 [复用审核报告](../audits/2026-09-01-rain-classic-reuse-audit.md) 与 [复用关系表](../../evidence/rain-classic/reuse-matrix.yaml) 中的 TextButton 条目。Classic 源文件不因此被删除或停用。

### TB-02 · 操作型文字按钮：三种颜色与浅底反馈

| 用途 | 平时文字与图标 | 悬停底色 | 按下底色 |
| --- | --- | --- | --- |
| 普通操作，默认使用 | 灰蓝 | 浅灰蓝 | 同色系略微加深 |
| 需要突出 | 主题蓝 | 浅灰蓝 | 同色系略微加深 |
| 有真实风险的操作 | 危险红 | 浅红 | 同色系略微加深 |

- 平时无底、无边；这里的“无边”不取消键盘操作时的提示轮廓。
- 悬停、按下时保留原来的文字与图标颜色，不把普通灰蓝自动变成主题蓝。
- 普通图标跟随所在文字按钮的颜色；仅保留已经登记的“颜色属于图标身份”例外，不新增例外，不改变已受治理的图形几何。
- 危险红沿用已经验收的 Rain Next Button 危险文字色系，不另造一套红。
- 警告橙明确不提供；这只约束本稿的文字按钮，不表示删除其他组件的警告色。
- 上表确认的是颜色职责和变化方式，浅底的最终深浅仍需实测。

### TB-03 · 三档字号，保留紧凑的文字操作尺寸

| 设计尺寸 | 字号：已确认 | 高度：已接受为实测候选 |
| --- | --- | --- |
| 小号 | 12px | 20px |
| 紧凑号 | 13px | 24px |
| 常规号 | 14px | 26px |

- 采用原 Vue 文字按钮的 12／13／14px 字号分档，不统一成一个字号。
- 放进 Input 后，不自动改成继承 Input 字号。
- 不直接沿用普通 Button 的 28／32／36／40／48px 高度体系。
- 高度候选仍需检查是否好点、是否拥挤；特别是 20px 高度，不能仅凭数字就宣布点击区域合格。
- 项目字体仍遵守 Rain 的 PingFang SC 规则。

### TB-04 · 操作型文字按钮左右各留 6px

- 三档文字按钮左右各保留 6px 内部留白。
- 这部分留白属于可点击区域，不只是控件之间的外部间距。
- 此决定不自动要求正文链接左右也各空出 6px；正文链接的排版不能机械套用按钮盒子。
- 上下留白、图标间距、圆角、行高和默认尺寸映射没有因为这一项确认就全部锁定，见第 3 节。

### TB-05 · 四种图文组合全部保留

保留纯文字、左图标加文字、文字加右图标、左右图标加文字四种组合。

- 平时优先纯文字或单侧图标。
- 两侧都有图标时，必须各有用途。例如左侧识别操作，右侧箭头表示展开。
- 每侧最多一个图标，文字与图标共同触发同一个操作。
- 不为了装饰而增加双侧图标。
- 构成已经确认，图标实际大小、间距与视觉居中仍需在三档尺寸中检查。

### TB-06 · 加载沿用全局图形与动效

- 使用与 Rain 已确认的通用加载反馈一致的图形和旋转动效，不换成另一种默认转圈图标。
- 加载图形出现在左侧：有左图标时替换它，没有左图标时在左侧加入。
- 加载期间暂时隐藏右图标。
- 默认保留原文案，例如“导出”；有明确需要时可以由使用场景提供“导出中”等文案。
- 不统一改成含义模糊的“处理中”。
- 加载期间阻止重复触发。
- 加载图形加入、右图标消失或文案变化时是否挤动布局，必须实测；当前没有确认固定宽度或其他防跳动方案。

该反馈不等于文字按钮负责真实请求、保存结果或所有链接的路由加载；职责边界见第 6 节。

### TB-07 · 禁用保留原色系，但明显变淡

- 灰蓝、主题蓝和危险红禁用后仍保留各自色系，不统一改成另一种灰色。
- 禁用时不出现悬停浅底或按下反馈，也不能触发操作。
- 文字与图标使用原色约 30% 的不透明度，作为浅色页面的实测候选；不是最终视觉验收数值。
- 这里的 30% 指前景文字与图标，不是无条件把整个控件及焦点提示一起设为 30%。
- 禁用与加载是两种状态，不能把这套禁用淡化效果直接套到加载中。

### TB-08 · 键盘操作时有清楚、轻量的蓝色提示

- 用 Tab 移动到文字按钮时，显示细蓝色轮廓，加一层浅蓝外圈。
- 外圈沿用已讨论的 20% 不透明度作为实测候选。
- 细轮廓与浅外圈是两部分，不能只剩一个很淡、难以辨认的光圈。
- 键盘焦点移走后，提示消失；平时仍保持无底无边。
- 轮廓粗细、外圈宽度与位置需实测，不因 20% 被接受就把所有几何值一并写成通过。
- 放入 Input 后，必须检查文字按钮与输入框自身的提示是否拥挤或形成双重外圈。不能为了简洁而取消必要的键盘提示。

### TB-09 · 跳转型文字默认主题蓝，悬停只加深文字

- 默认使用主题蓝，例如真正跳到另一页的“查看课程详情”“使用帮助”。
- 悬停时只让文字颜色加深，不铺底色。
- 不把操作型文字按钮的浅底反馈套给链接。
- 此项确认默认颜色方向与悬停方式；链接按下时的具体深浅没有单独锁定。

### TB-10 · 下划线按位置区分

| 放置位置 | 规则 |
| --- | --- |
| 独立入口，例如操作区的“查看详情” | 平时和悬停都不加下划线；保留只加深文字的悬停反馈 |
| 正文中的链接，例如“操作方法请查看使用帮助”中的“使用帮助” | 一直保留细下划线，帮助它与普通文字区分；悬停不新增底色 |

独立入口没有下划线时，所在位置与文案仍需让人看出它可以点击；不是所有混在正文里的蓝字都能按独立入口处理。

### TB-11 · 访问过后仍保持主题蓝

- 链接访问后返回原页面，不自动变成紫色或灰色。
- 已确认的悬停和下划线规则继续有效。
- “点开过”不等于“已读、已学完、已处理”。这些业务状态需要由页面明确表达，不由链接访问记录推断。

### TB-12 · 默认当前页，必要时另开并明确提示

- 默认在当前标签页跳转，例如从课程列表进入课程详情。
- 需要保留当前工作位置时，可以由具体页面指定新标签页。例如填写课程信息时查看帮助。
- 确需另开时，应提前明确提示“在新标签页打开”。
- 不因目标是外部网站就一律另开。
- 保留用户主动右键选择新标签页打开等真正链接的使用方式。
- 另开标签页不等于自动保存；是否需要保存提醒仍由业务页面负责。

### TB-13 · 短操作完整单行，正文链接自然换行

- 操作文字和独立短入口默认单行、完整显示。
- 不自动缩小字号，也不自动把操作名称裁成省略形式。
- 放不下时，由使用场景在不改变操作含义的前提下调整文案或布局，不能挤坏输入框或相邻内容。
- 正文链接可以随段落自然换行，保留完整文字与细下划线。
- 本条不能被理解为允许长文字无限撑破容器；窄屏、放大与长文案都要进入组合检查。

### TB-14 · 输入框内的文字操作默认常驻

- 当输入框已经设置了明确的文字操作时，平时就显示，不等悬停或聚焦后才出现。
- 暂时不可用时变淡，但保留位置。
- 这不要求每个输入框都必须有文字按钮。
- “清除叉号”与文字操作分开，清除的显示条件留到 Input 单独讨论。
- 本条不自动改变业务权限的显示策略，也不决定空值、只读、错误或加载期间的全部输入框行为。

## 3. 哪些还不能写成最终验收值

### 3.1 已有方向，等待真实页面微调

| 项目 | 目前依据或候选 | 后续要检查什么 |
| --- | --- | --- |
| 三档高度 | 20／24／26px | 点击是否容易、是否与文字和宿主高度协调 |
| 禁用淡化 | 浅色页面前景约 30% 不透明度 | 是否明显不可用，又能辨认原来是什么操作；不套用到加载 |
| 键盘外圈 | 浅蓝 20% 不透明度，加细蓝轮廓 | 是否清楚、是否过重、是否在 Input 内拥挤 |
| 灰蓝、主题蓝的具体文字色与状态色 | 保留 Rain 色系；项目主品牌蓝仍固定为 #1561F8 | 将角色正确映射到已有或正式补充的语义色，不能另定义主品牌蓝 |
| 危险文字色 | 复用已验收 Button 危险文字色系；当前文字色基准为 #C9343F | 三档文字、图标、禁用与浅红底是否协调；不要把实心危险背景 #EF5353 当成所有危险文字的颜色 |
| 悬停与按下的浅底 | 普通和突出操作用浅灰蓝，危险操作用浅红 | 层级是否清楚、灰蓝文字是否仍保持灰蓝、按下是否过重 |
| 加载布局 | 左侧加载、保留或明确替换文案、隐藏右图标 | 四种图文组合切换时是否跳动或挤压相邻内容 |
| 输入框内组合 | 常驻、禁用保留位置、三档字号 | 不遮挡输入文字，不挤占输入区域，焦点提示不冲突 |

表中数值分属不同对象：20% 是外圈候选，30% 是禁用前景候选；不能混为同一套透明度规则。普通 Button 已确认的其他禁用或加载透明度，也不是本稿的新默认值。

### 3.2 尚未单独决定，需要在实现方案或相应组件讨论中补齐

- 三档尺寸的默认选择，以及与页面 Compact／Default 密度、不同 Input 高度的具体搭配。
- 图标尺寸与间距、上下留白、行高、字重、圆角，以及焦点轮廓和外圈的精确几何值。原库数值可以作为有来源的候选，不能冒充本轮全部已确认。
- 链接的按下状态、禁用与加载的具体组合，以及正文链接的字号、行高、点击范围和多行焦点表现。已确认默认主题蓝，不等于自动提供操作按钮的整套颜色矩阵。
- 点击输入框内的文字操作后，光标应留在哪里；加载期间输入框是否仍可编辑；中文输入和 Enter 如何配合。它们由宿主输入组件和具体操作语义共同决定，不由本轮常驻规则代替。
- 输入框清除叉号的显示与状态规则，Input 自身的激活外观和其他尚未验收的 Input 设计。

这些不是要求设计师现在逐条重答。后续应区分需要展示给设计师的实际差异、可沿用的标准行为和必须明确的职责边界，再准备最小方案。没有证据的事项保持待验证，不用“先实现再看”静默越过。

## 4. 以后真实使用时，设计师需要检查什么

以下是待制作的验收材料清单，不是本次已经运行或通过的结果。所有勾选项目前均为空。

- [ ] 对比普通灰蓝、主题蓝、危险红：默认层级清楚，且没有警告橙。
- [ ] 分别移入、按下：操作型出现正确浅底，普通灰蓝不变成主题蓝；链接始终不铺底。
- [ ] 对比 12／13／14px 三档文字：清楚、紧凑、不拥挤，大小按钮都容易点到。
- [ ] 对比四种图文组合：图标位置协调，双侧图标各有用途，整体只有一个点击目标。
- [ ] 触发加载：与已验收 Button 使用同一图形和动效，文案有意义，右图标暂时隐藏，连续点击不重复执行。
- [ ] 对比禁用与加载：能看出两者不同；禁用保留原色系且无悬停、按下或点击反应。
- [ ] 用 Tab、Shift+Tab 移动：能看清当前落点，焦点离开后提示消失；输入框里不拥挤、不出现不明的双重外圈。
- [ ] 体验独立链接与正文链接：下划线正确，正文可自然换行；访问后仍保持主题蓝。
- [ ] 体验链接打开方式：默认当前页；指定另开时提前提示；右键打开与复制链接可用。
- [ ] 放入输入框：文字操作常驻，暂不可用时保留位置，加载和长文案不会挤坏输入区域。
- [ ] 检查窄空间与放大效果：短操作不变成省略号，也不偷偷缩字；放不下的问题被布局明确处理。

实际演示应先使用独立文字操作、简单输入框组合和一段正文链接，不需要为了这份验收先实现新的 Table、Card、Popup 或业务页面。没有真实实现与设计师确认，不给这些项目打勾。

## 5. 来源与成熟组件库对照

### 5.1 如何使用这些参考

外部规则核对日期为 2026-09-03。外部组件库可能继续更新；它们是可核对的设计依据，不是已安装的依赖。Rain 的已确认决定优先，不把参考库默认外观直接换成蓝色。

| 来源 | 本次参考的思路 | Rain 的明确取舍 |
| --- | --- | --- |
| Rain Classic TextButton | 三档字号和紧凑高度、左右留白、图文组合、通用加载资产 | 保留来源价值；普通动作改为默认灰蓝；不提供原库的警告橙；危险动作浅底分开处理 |
| [shadcn/ui Button](https://ui.shadcn.com/docs/components/base/button) | 共用按钮外观时仍让真正跳转保持链接含义；图标与加载内容可以组合 | 不建立重复的 TextButton 公共身份；不据此选择 Headless 库或照搬默认外观 |
| [shadcn/ui Input Group](https://ui.shadcn.com/docs/components/base/input-group) | 输入、附加文字、按钮等清楚组合，并考虑焦点顺序 | 文字操作与输入框各自保留职责；其文档中的尺寸名称不是 Rain 的像素依据 |
| [Ant Design Button](https://ant.design/components/button-cn/) | 区分文字操作与链接呈现，提供危险、禁用和加载等状态，危险色有配套浅底 | 借鉴状态完整度，不复制红色、字号或淡化比例；Ant 默认蓝色链接悬停更浅，而 Rain 选择加深，两者不能混写 |

| [Material UI Link](https://mui.com/material-ui/react-link/) | 下划线可常驻、悬停显示或不显示，默认常驻 | Rain 按正文与独立入口区分，而不是所有链接采用同一种下划线策略 |
| [Carbon Link](https://carbondesignsystem.com/components/link/usage/) | 区分正文与独立链接；访问过后的特殊样式默认不启用，按需要谨慎使用 | Rain 访问后保持主题蓝；Carbon 的独立链接会在悬停等状态加线，这一点不照搬 |
| [Carbon Button](https://carbondesignsystem.com/components/button/usage/#overflow-content) | 不建议截断按钮名称，内容过长时允许换行 | Rain 紧凑的短操作保留单行，把放不下交由布局处理；正文链接可以换行 |
| [GOV.UK Links](https://design-system.service.gov.uk/styles/links/#opening-links-in-a-new-tab) | 避免无必要的新标签页，确需另开时告知用户 | 默认当前页，必要时由页面明确另开并提示 |
