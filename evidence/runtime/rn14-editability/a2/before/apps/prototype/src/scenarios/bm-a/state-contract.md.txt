# BM-A 状态与事件合同

当前课程资料库的场景决定，非公共Table默认规则。沿用2026-09-14用户确认的页面；实现入口`#bm-a`，完整数据集在本地，刷新模拟异步返回，发布只改变本地记录。

| 状态/事件 | 结果与不变量 |
| --- | --- |
| 输入关键词 | 只改变草稿；搜索按钮或Enter才应用 |
| 搜索、发布状态、清空筛选 | 清空所有页选择并回首页；结果数是过滤后的总数 |
| 翻页 | ID选择集合跨页保留；数量包含其他页并明确注明 |
| 当前页全选/取消全选 | 只修改当前页可操作记录；只读项排除；半选明确 |
| 点击行/卡片空白、标题或更多操作 | 不改变选择；仅Checkbox及其关联标签触发选择 |
| 取消选择 | 清空全部页选择；三级按钮仅有选择时出现 |
| 批量发布 | 一级按钮常驻；无选中/加载时禁用；仅已选且可操作记录改为已发布，其余记录不变 |
| 表格/卡片切换 | 保留查询、排序、分页、选择；显示列仅影响表格 |
| 默认/紧凑密度 | 顶部“紧凑密度”勾选为紧凑，取消为默认；统一控制场景密度，不重置当前视图、查询、分页或选择 |
| 排序 | 默认/资料名称升序/降序明确选择；回首页，选择仍按ID保留 |
| 刷新开始 | 保留旧内容；清除旧错误/反馈；禁用修改与选择；同一宿主仅一个请求进行中 |
| 刷新成功 | 应用完整资料集；按现有筛选模型保留当前查询范围内仍存在且可操作的已选ID，跨页保留；不存在、变只读或离开查询结果的选择统一移除并说明总数；页码收敛到有效范围 |
| 刷新失败（含重复ID） | 旧内容、查询、页码、选择保留；错误与重试可见；不应用部分结果 |
| 卸载或更换读取函数 | AbortSignal中止旧请求；宿主失效标记同时生效，即使读取方忽略中止，迟到成功/失败也不得覆盖新状态 |
| 无数据 | Empty empty-box；提供本地示例恢复入口 |
| 筛选无结果 | Empty empty-search；清空筛选可恢复 |

`loadRecords(currentSnapshot, signal)`是本地宿主读取接缝，接收当前记录的副本。默认450ms后返回完整快照；不代表远程接口、服务端分页、持久化或真实权限。批量操作同步应用本地状态；刷新不会把本地已发布资料恢复成旧状态。本场景禁止结果全集全选，数据引擎不进入公共UI。

视觉来源：VE-001筛选/标签/表格/分页、VE-009批量与紧凑节奏；当前布局采用已确认的Rain Next实例。Inspector不在本任务的BM-A登记评估范围中，不因此建设完整BM-C。
