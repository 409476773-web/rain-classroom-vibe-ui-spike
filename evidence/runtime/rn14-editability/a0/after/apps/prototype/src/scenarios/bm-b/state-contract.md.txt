# BM-B 教材表单状态合同

身份：`local-experiment`；Recipe：`bm-b-textbook-dialog`；来源：VE-014 教材任务结构、现有公共 Dialog/字段/Layout，RN-07 Textarea 来源摘要见本批 textarea-source.json。入口：独立 prototype `#bm-b`。不进入公共 Block/Template/Upload/Sheet Registry。局部 CSS 只修改本页 Content/Header/Body/Footer 组合与原生附件输入；使用已有 Rain 字体、Space、Line、Radius、Text/Neutral/1/2/3、Text/Red/1、Background/Neutral/1/2、Border/Neutral/3，未新增 Token；晋升未提议。

| 事件 | 状态与结果 |
| --- | --- |
| 显式打开 | 深复制已保存教材与附件元数据，清除旧错误；焦点进入标题 |
| 编辑 | 仅改变草稿；当前字段错误随输入清除；宿主摘要不变 |
| 单/双列、宽/窄容器 | 只改变 Grid/容器几何，字段和草稿继续存在；窄屏自动单列 |
| 保存校验失败 | 定位字段并通过 FormItem 关联错误；学科由宿主校验 |
| 保存中 | 禁用字段、附件和提交；重复提交忽略；取消、关闭、Escape/遮罩被拦截 |
| 保存失败 | 草稿完整保留；底栏错误获得焦点，允许重试 |
| 保存成功 | 使用提交时副本更新宿主，关闭并恢复触发器焦点；只保留本页内存 |
| 取消/关闭/Escape/遮罩 | 保存中之外均丢弃草稿，中止全部未完成上传，不另加确认弹窗 |
| 上传 | 扩展名/非空/20 MB/最多10项校验；仅在内存模拟，不读文件内容，不请求服务器 |
| 上传失败 | 保留文件名/大小，显示重试/移除；未成功附件阻止保存 |
| 上传重试/成功 | 同一附件 ID 更新状态；成功后才可随教材保存 |
| 移除/关闭/卸载 | 中止对应请求；即使回调忽略中止并迟到，也不能复活附件或更新保存值 |

取消是明确丢弃；演示选项可让下一次保存/上传失败，失败开关用后复位。课程、教材与附件内容均为虚构/用户本地选择。文件名仅用于当前画面，不进入追踪属性。完整 BM-B 七项范围以本地 Mock 评测；真实服务、对象存储、生产校验、AI生成、封面图库与原图装饰不在本次范围。
