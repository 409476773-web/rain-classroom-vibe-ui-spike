## 图表适配

- 版本核查：Recharts 3.10.1，MIT；React peer 支持 19，当前运行 React 19.2.8，直接 peer react-is 锁定 19.2.8。apps/prototype 唯一新增依赖；安装实际增加 36 个包，属于真实成本。元数据见 recharts-package.json，安装日志保留。
- [官方尺寸](https://recharts.github.io/en-US/guide/sizes/)与[该版本键盘说明](https://raw.githubusercontent.com/recharts/recharts/v3.10.1/storybook/stories/API/Accessibility.mdx)已核查。仅保留一个本地 TrendChart，不建设公共 Chart API。
- 同一数据、同一布局、同一 0–100 纵轴。系列与图例统一颜色，保持圆点/方点、实线/虚线；每次只显示当前班级系列。Tooltip 提供单位、班级和缺测，键盘左右键可逐周读数；固定周次读数与明细仍可独立访问。
- 不改变数据解释；禁用曲线动画与插值平滑；缺周/null 断线。单独数据夹具验证 null、零分母，以及渲染 SVG 的两段路径。
- 初次运行发现引擎把点绘制在独立图层，父级颜色不会自动传给点；已为点指定同一系列角色。键盘聚焦先显示首周，再用方向键移动；测试已按真实行为更新。
- 三浏览器源码与构建版均 27/27 通过，最终构建版证据在 bm-d-final/，日志 m2-built-final.log。包括 BM-C 原行为回归、BM-D 聚合/筛选/分页隔离、失败/空态、键盘读数、主题与窄屏；缺测路径定向用例 4/4 通过。
- 独立审阅修复并复核：ReferenceLine 子线条继承系列标记颜色；页面 strong/b 使用既有 600；两个宿主不接受空值的 Select 显式关闭清除。最终阻断/重要/次要均 0。点/线同色与参考线的实际绘制值见 independent-final.json 等证据。
- 依赖只进入 prototype；72 个新增锁文件块单独登记，移除新增块可恢复原锁文件。四批实现结束时 Shared UI、Layouts、Foundations 源码与实施前哈希一致，见 changed-files.json；随后授权的 Select 回归修复仅改变共享样式中的一条宽度声明，详见 select-repair.md。

- 最终完整浏览器回归 **294/296 通过、2 项失败**，完整运行 11.1 分钟，退出码 1；见 full-browser-final.log。无跳过或中断；两项 Select 几何失败已在单 worker 下复现。

| 原有问题 | 根因与实测 | 后续最小修复方向 |
| --- | --- | --- |
| Select 弹层未跟随宽控件 | 触发框 532px，弹层 320px；共享 rain-menu 的 max-width 覆盖 Select 使用场景。仅在诊断浏览器移除菜单上限后弹层恢复 532px | 单独核准共享 Select 弹层宽度规则，保留视口碰撞边界并回归四种 Select |
| Select 展示页窄屏溢出 | 320px 视口被代码示例的最小内容宽度撑至 420px；诊断中允许网格缩小并让 pre 内部滚动后恢复 320px | 展示页约束网格与代码块，保留代码阅读和触控检查 |

证据：select-causes.json、select-diagnostic.json、窄屏前后诊断截图。诊断当时相关共享源码、展示页源码和原测试均与 before.json 一致；只注入临时浏览器样式，没有修改源文件或放宽断言。这两项记录为原有缺陷，不归因于 Recharts。上述 294/296 为历史失败结果，后续修复没有覆盖原证据。
