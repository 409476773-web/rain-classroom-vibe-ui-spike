## 实际对象与操作

目标为本轮确有局部排版调整的资源头版本Tag。实际规则位于本页 `(max-width: 640px)`：

`.ru-resource-heading > [data-rain-id="ui-tag"] { grid-column: 2; justify-self: start; }`

测试从真实CSSOM定位唯一规则，在浏览器内把该规则的选择器临时改为无匹配作用域，随后恢复原选择器；没有注入演示控件，也没有改共享Tag样式。每个视口各有原态、去除局部作用域、恢复三阶段事实和截图。

兄弟观察对象是现有页头的“本地原型 · 虚构样本”Tag及“查看版本比较”按钮。页头Tag是neutral/outlined/24，目标Tag是brand/filled/24；比较按钮为secondary/medium。它们的变体与作用不同，本证据只把每个实例在前/后/恢复三个阶段与自身比较，不将不同变体或比例视为等价设计。
