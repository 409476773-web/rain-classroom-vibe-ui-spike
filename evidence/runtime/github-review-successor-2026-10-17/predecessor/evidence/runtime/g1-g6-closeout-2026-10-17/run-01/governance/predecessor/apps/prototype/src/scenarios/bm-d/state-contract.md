## 原 BM-D 数据与状态合同

身份：`local-experiment`。VE-007 为 AI 分析/摘要分层参考，VE-010 仅使用已登记的脱敏结构审计，不转录教师档案。数据全为新建虚构教学汇总：两班、6 周、每班每周应交 26 份，每条记录包含应交份数、提交份数和总分；每份作业满分 100。

| 指标 | 统计定义 |
| --- | --- |
| 应交作业（份） | 完整筛选集 expected 之和，跨周为作业份数，非去重学生数。 |
| 实际提交（份） | 完整筛选集 submitted 之和，同一学生跨周提交分别计份。 |
| 平均分（分） | scoreTotal 总和 ÷ submitted 总和；按提交份数加权，不对周均分直接求均值。没有提交时显示破折号。 |
| 提交率（%） | submitted 总和 ÷ expected 总和 × 100；分母为零显示破折号。 |

页面拥有数据源、班级/周期筛选和请求状态，先筛选完整数据再聚合。明细展示完整筛选集，最多 12 条；KPI 同样按完整筛选数据统计。Loading/Error 时不显示旧指标；失败有聚焦提示及重试，空集有恢复入口。复用可取消模拟任务，同步锁阻止重复请求，卸载取消并忽略迟到结果。

图表只拥有展示指标（平均分/提交率）和选中周，不修改数据源、统计范围或 KPI。周度系列按同一公式独立计算，纵轴固定 0–100。一班实线圆点、二班虚线方点，并提供命名的周次 Select、固定读数区域和完整等价数据表；图上提供悬停与左右键即时提示，不依赖颜色区分。数值为坐标而非 CSS 视觉配置。图表采用页面局部 Recharts 3.10.1，纵轴不截断；六周范围内缺测保留 null，曲线断开、提示显示“缺测”。零分母仍显示无值，不填零。单独夹具验证缺周与实际 SVG 断线，主样例数据不变。接入真实服务前仍需服务端数据验证。
