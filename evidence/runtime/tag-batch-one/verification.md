## 操作区尺寸修正（2026-09-09）

用户要求可操作区域适应不同尺寸。删除原固定 24px Tag action Token 与 utility：关闭反馈由原生 stretch + aspect-square 取根内高，Link 主操作去掉 24px 最小高度，选择区保持整标签。Small 的关闭图标也复用本档 12px，其他为 14px。三档可视反馈在标签内部，不裁切共享 Focus；以 Space/6 的一半（3px）保留透明点击余量及相应空间，桌面关闭目标为 24/28/32，触屏纵向扩大为 Space/14。

浏览器回归先复现 Small 20 的关闭反馈为 24×24、上下各溢出 2px；修正后为 18×18、上下各留 1px。独立复核又捕获小档真实目标宽度不足，补充用例复现18px不足24px；修正后桌面实际目标逐档为24/28/32，点击可视关闭背景左侧2px会正确移除，且不触发链接。
