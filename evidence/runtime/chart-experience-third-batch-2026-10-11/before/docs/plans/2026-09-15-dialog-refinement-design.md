## 2. 定义与蒙层

Dialog 用于承载需要用户集中注意力的阅读、判断或操作任务，保留当前页面上下文，具有较强打断性。常规模态 Dialog 使用蒙层，默认点击蒙层不关闭。

所有百分比统一表示不透明度（Alpha）。

| 层级 | 浅色模式 | 深色模式 | 用途 |
| --- | --- | --- | --- |
| 无 | 无蒙层 | 无蒙层 | 普通 Popover、菜单等无需遮蔽背景的场景 |
| 视觉区分 | #223051 / 6% | #05091A / 15% | 复杂背景下的轻量视觉分离 |
| 轻度聚焦 | #223051 / 15% | #05091A / 70% | 包含需要适度注意的重要操作的轻量面板 |
| 模态任务 | #223051 / 50% | #030510 / 90% | 常规 Dialog、模态抽屉 |
| 特殊沉浸 | #1B2338 / 80% | #05091A / 90% | 明确要求高度遮蔽背景的特殊场景 |

深色的模态任务与特殊沉浸具有不同用途，两项颜色及90%的不透明度均已明确确认，分别保留。

蒙层作为专用语义 Token 管理，复用既有 Foundations 登记、生成及主题机制。无蒙层表示不绘制蒙层。实际 Token 键名在实施时遵循现有命名合同。

蒙层颜色、背景可操作性、关闭策略分别定义；菜单和 Popover 默认无蒙层。有轻量蒙层时，点击可关闭当前弹层。模态任务与特殊沉浸默认不因点击蒙层关闭。

## 3. 尺寸、位置与滚动

### 3.1 宽度

- 标准档位：416、516、616、716、816、916、1016、1116px。
- 采用指定宽度系列，不再将该系列表述为全部可以被8整除。
- 普通 Dialog 默认宽度为616px。
- 宽度指整个弹窗外框，包含内边距和边框。
- 416px为桌面最小设计宽度，普通弹窗通常不超过1116px。
- 普通弹窗在打开时选择档位，增加错误提示或进入加载状态不会自动切换档位；大屏上保持所选宽度。
- 明确不进入新页面的大型复杂任务，可显式选择随可用视口扩展，允许超过1116px。
- 可用空间不足时，实际外框宽度受视口约束，不为维持416px下限而横向溢出；双列内容相应退化为单列。

| 内容需求 | 档位选择参考 |
| --- | --- |
| 简短确认、少量信息 | 416 |
| 单列表单、常规设置 | 516 / 616 |
| 较复杂表单、双列信息 | 716 / 816 |
| 多区域操作、复杂信息面板 | 916 / 1016 / 1116 |
| 明确的大型任务 | 随视口扩展 |

此表是选型参考，双列与否仍取决于实际内容，不由宽度数字自动决定。

### 3.2 视口边距

| 场景 | 最小安全边距 |
| --- | --- |
| 常规桌面 | 默认40px |
| 明确采用大留白方案 | 60px |
| 窄屏 | 16px |

- 安全边距是最小距离，不要求固定宽度弹窗恰好贴着该边界。
- 例如1440px视口中的616px弹窗水平居中，实际左右留白各412px。
- 375px窄屏左右各留16px时，最大可用弹窗宽度为343px。
- 窄屏的具体切换阈值尚未指定，实施样例应结合既有响应式约定确定并验证。

### 3.3 高度及位置

- 默认水平、垂直居中。
- 最小高度128px，指包含Header、Body、Footer的整个外框；这是下限，不要求完整内容恰好装入128px。
- 高度随内容自然增长；短内容不强留长内容的空白高度。
- 最大高度为当前可用视口高度减去上下安全边距。例如900px视口、上下各40px，最大高度为820px。
- 达到上限后，Header和Footer保持可见，Body负责正文滚动。
- 极矮视口、浏览器缩放、软键盘出现时，可达性优先于最小尺寸；关闭和提交操作保持可达。
- 页面背景锁定滚动；正文滚到边缘时不带动背景页面。
- 内部Select、Popover、菜单显示在所属Dialog之上，不被正文滚动区域裁掉。
- 校验失败时，首个错误字段应进入可见区域，底部操作保持可达。

## 4. 已确认的底部按钮规则

- 两个按钮时，取消在左，主操作在右。
- 按钮间距允许8px或12px，按场景选择，同一弹窗内保持一致。
- 通常设置1个一级按钮作为弹窗内的主操作按钮；取消及其他辅助操作保持次要层级。
- 主操作的视觉层级与默认键盘焦点分别决定，危险确认可以将初始焦点放在取消上。

间距须作用于实际按钮组。当前课程示例由course-dialog-actions管理按钮间距，不能只改变Footer外层间距就宣称完成。

## 5. 已确认的动效

| 对象 | 打开 | 关闭 |
| --- | --- | --- |
| 蒙层 | 淡入到对应主题和用途的目标不透明度 | 淡出 |
| 常规弹窗 | 淡入，同时从98%轻缩放至100% | 淡出，同时轻缩回98% |
| 接近全屏的大型弹窗 | 仅淡入 | 仅淡出 |

- 开关时长采用180ms，各蒙层层级使用相同时间规则。
- 蒙层与弹窗同步开始，保持中心位置稳定。
- 快速反向操作从当前进度平滑衔接，不等待完整入场后再退场。
- 开关过程中避免误触背景页面。
- 系统启用减少动态效果时，取消过渡，沿用现有0ms规则。
- 校验、加载结果等内容变化不重复播放入场动画。

复用[现有Rain Motion](../../packages/foundations/src/motion.css)的时长与曲线；过渡接入Base UI现有生命周期。当前Dialog的居中变换须与动效变换协调，不能直接覆盖居中定位。动画设计已确认，视觉效果尚需运行样例验证。

## 6. 已确认的多层弹窗规则

常规流程最多保留一个主任务弹窗，加一个必要的临时确认弹窗。例如：编辑教材 → 请求关闭 → 确认是否放弃修改。

- 确认出现后，父弹窗保留草稿和滚动位置，暂时不可操作。
- 选择继续编辑，只关闭确认弹窗，返回父弹窗中的合理位置。
- 选择放弃修改，按明确的业务结果关闭确认和编辑弹窗。
- Esc只处理最上层，不同时关闭两层。
- 连续复杂子任务优先在当前弹窗内分步完成，避免连续叠加编辑窗口。
- 同一时间只保留一层有效的全屏蒙层，由最上层模态弹窗接管；避免多层透明颜色叠加改变已确认效果。
- Dialog内部的Select、Popover、菜单沿用当前蒙层，显示在所属弹窗之上。

这里限制的是有效绘制与交互结果，不凭DOM节点数量判定合格。确认关闭后，父弹窗蒙层、焦点和滚动锁应正确恢复；最后一层退出后恢复页面。

## 7. 已确认的普通Dialog与AlertDialog分工

| 项目 | 普通Dialog | 确认弹窗AlertDialog |
| --- | --- | --- |
| 任务 | 编辑、设置、阅读 | 理解后果并作出决定 |
| 内容 | 可包含表单、分区及长内容 | 聚焦一项决定 |
| 默认宽度 | 616px | 416px，内容需要时按标准档位加宽 |
| 常规动作 | 取消与保存等主操作 | 安全退出与明确执行动作 |
| 初始焦点 | 按任务选择字段或标题 | 高风险操作优先聚焦安全选项 |

两者复用Rain外观、尺寸和蒙层体系，保持各自语义。一级危险操作按钮可以作为视觉主操作，初始键盘焦点仍可放在取消。成功、失败、警告等反馈优先通过内容或场景组合表达，不据此分别建立独立组件家族。

## 8. 其他实施输入：既有候选与讨论建议

以下内容已讨论或来自现有候选；本轮按钮确认不扩展为这些内容的全面视觉接受。

### 8.1 关闭与保存流程建议

- 右上角关闭、取消、Esc使用相同的关闭请求流程。
- 无修改直接关闭；存在未保存修改时，重要编辑任务提示放弃确认，提供继续编辑与放弃修改。
- 已有可靠自动保存或草稿恢复的场景，按其实际保存机制处理。
- 保存时防止重复提交，必要时暂时阻止关闭；失败后保留输入并允许重试或退出；成功后更新结果再关闭。
- 长时间任务提供取消或转后台路径，避免无限期限制退出。
- 有蒙层的轻量弹层关闭时，避免同时触发背景操作。
- 草稿、修改判断、校验、保存、取消和重试归业务宿主；公共Dialog提供关闭请求与焦点等容器能力。

### 8.2 内部排布候选

2026-09-15后续截图反馈：用户明确“所有分割线，都应该使用颜色很浅的border颜色。现在看起来略深。”内容分割统一使用现有最浅的 `Border/Neutral/4`，厚度保持1px。本批落到公共Separator、Dialog Footer divider和BM-B全部分区线；不改动Border Token数值或控件边界。浅色10%、深色5%分别消费既有主题配对。该要求更新之前对分割线颜色的视觉接受；本批实际运行画面仍待确认。

| 项目 | 现有或建议值 |
| --- | --- |
| 外框 | 10px圆角、1px边框、现有Dialog阴影 |
| 标题区上、左、右内距 | 24px |
| 标题与说明 | 标题18/28/600，说明14/24/400，间隔8px；无说明不留空位 |
| 标题说明组到正文 | 24px，只由一个区域负责 |
| 正文左右及末尾到底部分界 | 24px |
| Footer内距 | 上下16px、左右24px |
| Footer表面与分割线 | 根据2026-09-15截图反馈：与主体共享底色；默认无分割线，长表单按需开启divider |
| 表单分区与字段间距 | 分区24px、完整字段间20px作为常规候选；字段内部复用FormItem |

2026-09-15整体验收补充：BM-B标题/说明统一为8px；当前BM-B的完整字段与网格间距16px，经单双列和窄屏画面检查保留，分区仍为24px。20px为常规候选，不强制覆盖所有表单密度。同日后续用户浏览器批注2明确要求BM-B右上角使用规范IconButton，取代之前保留的文字关闭入口；采用已确认28/20的CloseBoldIcon。

补充讨论规则：

- 标题、说明、正文共享左边线，主操作与正文右边线对齐。
- 标题与关闭按钮至少间隔16px；按钮与标题第一行垂直居中，标题换行时按钮保留完整点击区域。
- 标题优先描述任务，超长对象名称完整放在正文；特殊无视觉标题场景仍有读屏名称与关闭入口。
- 同一视觉容器、同一方向遵守边缘留白 ≥ 分区间距 ≥ 分区内信息间距，避免留白重复累计。
- 双列表单顶部对齐，完整字段包括帮助和错误信息；大弹窗不自动放大控件或字体。
- 单按钮自然宽度靠右；辅助动作保持次要层级；纯阅读内容可省略Footer并保留关闭入口。
- 窄屏先将正文改为单列，允许标题、说明和错误换行；状态移到上一行后尽量保留双按钮同排，仍放不下时再纵排。
- 按钮复用现有完整尺寸方案，不通过缩小文字、挤压点击区域或截断按钮文案适配窄屏。

来源与已有验证范围见[组合排版规则](../audits/2026-09-13-composition-layout-rules.md)。其中旧480/560px示例宽度是历史记录，后续改造按本轮尺寸规格选型。

## 10. 后续实施与验证输入

实施时沿用现有Foundations、Dialog Parts、Popup主题与密度桥接，以及Base UI的关闭、焦点和生命周期能力。按变更范围同步Token登记、Manifest、Registry、消费者与文档示例。

至少覆盖：

- 浅色/深色五档蒙层的实际颜色合成，无蒙层场景及单层有效绘制。
- 416、616、1116、随视口扩展样例，320/375px窄屏、极矮视口与缩放。
- 短内容、长内容、固定头尾、内部Select与菜单不被裁切。
- 实际按钮组8/12px间距、一级主操作、长标题和长按钮文案。
- 点击蒙层不关闭、Esc逐层处理、放弃确认、安全焦点及关闭后焦点返回。
- 嵌套确认前后草稿、滚动位置、蒙层和背景滚动锁恢复。
- 保存中、失败重试及成功关闭，业务状态保留在宿主。
- 入场/退场、中途反向、减少动态效果与开关过程的背景误触检查。

后续新增证据保留各批次边界，不改写旧通过、失败或受保护快照。当前Dialog仍为registry-candidate；原视觉Human Gate、深色焦点对比度问题及对比度接受分别保留，见[当前阶段](../../status/current-phase.yaml)和[既有精修验证](../../evidence/runtime/dialog-visual-2026-09-13/verification.md)。本文不改变组件、Figma、发布、业务迁移或Git提交状态。
