## 3. 组件职责候选

| 层次 / 对象 | 提供的能力 | 主要内容或动作 |
| --- | --- | --- |
| 基础 Tag | 名称、完整颜色方案、外观、尺寸、前标识、可选移除 | 根容器 → 前标识 → 文本 → 独立移除按钮 |
| CheckableTag / CheckableTagGroup | 明确的单选或多选 | 标签主目标切换选中；组负责值、互斥、清空及键盘顺序 |
| LinkTag | 标签形态的导航 | 主链接；必要时单列外链标识和移除按钮 |
| TagSelect | 以标签作为触发器的单值选择 | 当前值、展开指示、候选列表；保留旧库独立身份 |
| 标签选择与创建 Pattern | 搜索、复用、多值选择、创建、选色、失败反馈 | 已选标签区 + 添加入口 + 选择 / 创建流程 |
| 系统状态及 Domain 标签组 | 固定内容类型、难度、分组方式、业务状态、提醒与计分等含义 | 将业务值映射至既有完整颜色方案及专用 Parts |

基础 Tag 的名称、颜色身份、外观、尺寸与移除事件分别表达。保留 Next 现有 `appearance` 与 `onRemove` 的职责；颜色入口只接受已登记身份。结构预览确认后，已在[第一批接口与实施计划](2026-09-09-tag-batch-one-implementation.md#2-公共接口)收口 API 方案。现有 `tone="neutral" / "brand"` 消费列入兼容清单，不能直接删除旧示例。

通用标签颜色与业务名称分开：同一个已登记颜色方案可以显示“期末复习”等自定义文字；“课堂”“视频”等固定业务含义由 Domain 映射提供。Tag 不根据文字猜颜色或功能。

## 4. 完整尺寸基准

以下继承旧库共享横向外壳；首轮预览已展示三档，纳入用户“其余视觉目前没问题”的反馈。真实组件及未展示组合仍需实施验证。单位 px。

| Size | 高度 | 字号 / 行高 | 左右内距 | 内部间距 | 圆角 | 前标识盒 |
| --- | --- | --- | --- | --- | --- | --- |
| Small | 20 | 12 / 14 | 6 | 4 | 4 | 12 |
| Medium | 24 | 13 / 18 | 8 | 4 | 6 | 14 |
| Large | 28 | 13 / 18 | 12 | 4 | 6 | 14 |

共同规则：border-box；透明边框仍预留 1px；宽度随内容，长文本单行省略；Solid 700，其他外观 400。显示完整名称的方式应覆盖键盘与触屏，不能仅依赖鼠标悬停。

默认方案：高密度列表中的静态标记用 Small20，普通区域和可移除 / 可选择标签用 Medium24，Large28 由明确场景选择。父级 Density 选取完整方案，显式 Size 优先，不将所有数值按比例缩放。这些是 Tag 的局部方案，不建立新的全局控件高度表。

关闭图形、反馈背景和点击区分别定义。2026-09-09 真实页面反馈修正了先前固定 24px 点击区：新版使用正式 `icon/close`，图标盒随本档为 12/14/14；关闭反馈背景以原生 stretch + aspect-square 适应标签内高，Line/1 下为 18/22/26。透明余量使桌面实际点击区为 24/28/32；触屏进一步纵向扩展并检查间距与重叠，见第 10 节。

竖向标签、业务 XL 状态、批量叠片、开放型作业双行、提醒角标和计分角标继续保留来源记录，各自核对专用几何。它们不直接套用上述横向三档。前一轮颜色图中的“批量”是色值样本，不是批量叠片的形状验收。

## 5. 交互候选

| 场景 | 交互与状态规则 |
| --- | --- |
| 静态展示 | 不增加焦点停靠和按钮语义；无操作时不附加可点击的 Hover / Pressed 暗示 |
| 移除标签 | × 只解除当前对象关联，具有包含标签名称的可访问名称；Enter / Space 可执行；文本区不会代替移除按钮触发 |
| 移除后焦点 | 集合优先落到下一个可操作标签，末项则前一个，空集合回到添加入口；集合管理此规则，单个 Tag 发出移除事件 |
| 单选组 | 使用单选语义；方向键在可用项中移动并选择；禁用项按组合同跳过 |
| 多选组 | 每项明确表达选中值；Space / Enter 切换；第一版采用直接可理解的原生键盘路径，复杂集合导航另行验证 |
| 分类色与选中状态 | 分类色持续标识同一个标签；选中勾显示在文字后，未选中时完全不占位；保留已展示的同色边界，不能仅靠轻微颜色变化 |
| 链接 | 主目标按链接工作；链接与移除动作是并列目标，避免交互元素嵌套；新窗口行为保持明确 |
| 只读 | 内容仍可读，移除、改名、改色入口按场景能力关闭；只读不等于需要整体淡化 |
| 禁用 | 阻止相应动作并表达不可操作；保留原因入口由外层提供；最终用色与透明度待真实状态核对 |
| 键盘焦点 | 消费 Rain Next 已接受的全局 Focus，不将旧 Vue 的焦点底色直接覆盖到新库 |

Hover / Pressed 的旧来源为当前 profile 的实底混色，禁用为整体透明度。它们进入来源清单，但尚未由本次静态色板完成交互验收。新增强制颜色、主题边界和实际父表面的验证时保留全局规则。

## 6. 自定义标签流程候选

1. 打开选择入口后先搜索已有标签；无同名结果时提供“创建并选中”。
2. 名称去除首尾空格并禁止空名称；同名判断与可用范围由业务词表合同提供。长度上限由实际业务要求决定，展示省略与存储限制分开。
3. 选色展示输入名称的真实 Filled 效果，保持完整 20 色可选。中性色可作为额外默认候选，不占用或替换这 20 组；其完整三种外观需另外核对。
4. 保存标签定义中的稳定 ID、名称与颜色身份；对象只保存关联 ID。同标签的多次引用保持一致，改名 / 改色更新同一定义。
5. 请求成功后显示正式选中结果。失败时保留名称、颜色和输入状态并允许重试；提交中阻止重复创建。
6. 搜索和创建复用现有 Input 的中文输入法保护；组合输入期间 Enter 不直接创建。网络请求、结果过期处理和数据权限由使用方负责。
7. × 移除关联；删除定义、改名、改色位于明确的编辑 / 管理入口。个人、课程、团队范围由使用场景提供，组件库不自建权限平台。

第一版不增加无需求的层级标签、合并、归档、拖拽排序或标签统计后台。既有 Toast / Message 等共享反馈能力按当前实际可用性复用，局部表单错误可直接留在创建区域，不创建 Tag 专用全局消息系统。

### 9.1 共同结构与动作

| 对象 | 本轮具体方案 | 责任边界 |
| --- | --- | --- |
| 普通 Tag | 文本；可选前图标；Filled / Outlined / Solid 三外观 | 静态容器不增加点击或焦点停靠；只读保持正常清晰度 |
| 带图标 Tag | 前图标盒 Small12 / Medium14 / Large14，距文字 4 | 正式图标继承宿主颜色；不根据标签名称自动猜测图标 |
| 可关闭 Tag | 文本直接衔接随尺寸变化的关闭区，去掉额外 4px 间隔；当前尺寸规则见第 10 节 | 保留独立点击范围；文本区不触发移除；根容器发出移除意图，由集合或使用方更新数据 |
| LinkTag | 主链接与关闭按钮并列；有关闭按钮时去掉主链接右侧额外内距 | 两个目标独立获得焦点；正文导航，关闭解除关联；外链提示沿用现有 Link 合同 |

尺寸保留 Small20 用于高密度静态内容，Medium24 作为交互默认，Large28 显式选择。三档按完整方案切换，内距、字体和图标盒不随高度等比例缩放。预览的尺寸对照同时保留三档，并允许单独切换交互样例的尺寸。

当前默认的“勾选 + 同色边界”纳入“其余视觉目前没问题”的反馈，勾选位置按本轮要求移到文字后。普通默认 Filled 仍无可见边框；选中边框是动作状态的提示，不改变已确认的普通标签外观。Outlined 已有同色边框，选中主要通过新增勾选识别。“仅勾选”仍是可选对照，不从默认方案反馈推导其独立验收。

### 9.3 选择、移除与键盘路径

- 单选使用原生 radio，同组方向键移动并选择，跳过禁用项；Space / Enter 可选择。不要将单选项实现成可被再次点击清空的独立开关。
- 多选使用原生 checkbox，Tab 依次到达可用项，Space / Enter 切换。清空后焦点回到首个可用项，防止停留在已禁用的清空按钮上。
- 点击关闭只移除该标签，焦点到集合中的下一个动作；没有下一项则到前一个动作，空集合回到外层添加入口。单个 Tag 不扫描或管理页面焦点。
- 预览中的撤销只恢复局部演示数据；正式组件发出事件，实际异步请求、失败回滚及反馈由集合或业务使用方负责。
- 链接预览在本地展开资源内容，关闭内容后焦点返回原链接；它是动作关系演示，没有接入真实资源库或业务路由。
- 触屏候选为可交互外层保留至少 44px 高度和互不覆盖的目标区域，内部标签维持所选外观高度；真实触屏操作仍留待实现后的设备验证。
