## 目标与最小合同

- Table / Header / Body / Footer / Row / Head / Cell / Caption 直接保留原生表格语义、属性与 ref；独立 TableScrollArea 提供具名键盘滚动区。表格不拥有数据处理、选择或请求。
- Pagination 使用现有 Rain Button，受控 1-based page / pageCount，保留首尾与相邻页，非法非整数/负值明确报错；超过末页仅显示合法页，不在渲染中触发回调。空集合禁用翻页。
- Empty / Title / Description / Actions 保留开放组合，区分没有数据和没有筛选结果；状态播报由宿主提供。
- 数据配方锁定 `@tanstack/react-table@8.21.3`（仅 prototype 应用），其精确传递依赖 `@tanstack/table-core@8.21.3`。使用同版本官方文档；当前 shadcn 指南已为 v9，不能复制 v9 API。Table UI 不依赖引擎。
- 全量虚构数据在客户端统一排序、筛选、分页；宿主持有查询、排序、分页、ID 选择、列可见性、视图及模拟加载状态。当前页全选只含可操作项；跨页和表格/卡片切换保留选择；查询改变清空选择并回到首页。列状态不控制卡片内容。
- 复用 SearchInput、Select、Checkbox、DropdownMenu、Tag、Card、Layout。模拟刷新失败保留数据和选择，重试成功；不引入请求层、虚拟化或全结果全选。
