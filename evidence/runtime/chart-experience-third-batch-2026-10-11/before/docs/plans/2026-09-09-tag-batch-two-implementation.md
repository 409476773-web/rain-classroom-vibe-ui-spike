# Tag 第二批实施

2026-09-09 用户明确授权：“确定。开始实施”。工作模式为 System Mode，资产保持 registry-candidate / unpublished。最终角标修订后用户回复“视觉没问题。继续推进”，本批实际视觉 Human Gate 已接受。设计依据为 [Tag 设计](2026-09-08-tag-design.md) 第 13–16 节，后续修订优先。

## 范围

- 新增 LearningUnitTag、DifficultyTag、GroupTypeTag、StatusTag、SystemStatusTag、LearningUnitReminderMark、ScoredTaskTypeMark 七个展示组件，固定业务映射与形状。
- 基础 Tag vertical 三档完整配方；所有 Solid 前景反白。Neutral 与已结束 Solid 消费已有 Slate 实底，不更改来源 RGBA。
- 计分角标完整内置右上角；scored 只切换角标，不改变主体配方。上下对称布局，正文居中；开放型作业两行同字号。
- 复用现有 Foundations → 生成器 → Tailwind → UI 链路，登记完整形状、用途、排版、Manifest、本地 Registry 和实际演示。

## 实施顺序

1. 补业务边界与 Solid 回归检查，先观察失败。
2. 在现有 Tag 事实源登记业务映射及完整几何，扩展生成与精确排版用途；复用 Tag surface 实现七个具名组件。
3. 同步授权、消费者、验证边界、Manifest / Registry、Tag 演示页。保留第一批历史验收和同期 Select 修改。
4. 跑聚焦检查及完整批次验证，真实浏览器核对三档、两主题、窄屏、文字放大、角标边界、强制颜色与减少动态。
5. 独立审阅后修复有效问题，保存第二批证据，交付用户视觉检查。

## 计分角标视觉修订

用户确认设计第 16 节，沿用第二批 System Mode 范围。目标为 Solid 的 30% 白底和不透明白字、Filled / Solid 共用 28×14 角标及外框各增 4px，保持当前字号、正文中心、开关行为。

1. 在现有业务颜色与浏览器用例中加入白色叠层、两外观分流和新尺寸断言，先复现旧配方失败。
2. 修改 tag-token-contract.ts 的完整计分尺寸；由已有 Fill/TagSolidAction/Alpha/1 显式替换为 Alpha/30，生成具名组件颜色配方。domain-tags.tsx 只在 Solid 使用该背景，不改整体 opacity。
3. 同步生成器、精确消费登记和叠层对比度测量，保留 4.5:1 正文阈值与未接受发现。复用现有 CSS 布局，不新增通用样式机制或色彩身份。
4. 运行相关单元检查、类型、构建、治理及 Tag 浏览器回归；复核两主题、三档、两外观、200% 文字、计分开关和强制颜色。独立审阅后更新本批证据；Human Gate 继续待实际检查。
