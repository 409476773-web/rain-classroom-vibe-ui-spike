# Tabs 视觉与布局修订验证

日期：2026-09-12。状态：本轮实现、自动验证及独立审阅完成；用户已明确确认当前版本运行视觉 Human Gate 通过。

当前阶段为 Token Foundations V1 下已授权的 Tabs 视觉修订；工作模式为 System Mode，资产仍为 registry-candidate。依据用户逐项确认的[设计](../../../docs/plans/2026-09-11-tabs-visual-refinement-design.md)及后续“继续推进”授权实施。首版结果保留在 `../tabs/`，本目录单独记录修订前问题与新验证。09-11 追加确认的蓝线限长及三档上限已经实施；下表为该增量后的最新完整结果。

## 本轮实现

- 线条形式默认采用 content 限长：28／32／38 尺寸的最大长度为 24／28／32px。横向取内容组宽度与上限的较小值；纵向取项高度与上限的较小值。指示线居中，短内容不被拉长。显式 indicatorSize="stretch" 保留旧自适应几何，等分排列时仍随分配的项宽伸展。完整与 Compound API 使用同一默认值，正式预览增加两种方式的切换。

- 三种外观共用 192px 纵向列和左右各 16px 内容留白。单行高度 28／32／38px；整组双行高度 46／52／60px，名称左对齐，混用图标时保留一致的名称起点。
- 图标与数量相对整个名称块垂直居中，数量紧随名称，不占统一末端列。普通数量完整显示；极长数量受剩余空间约束，保留真实值与全文提示。
- 底板四周背景内缩 3px，相邻背景净间距 8px。线条指示器两端为圆头。浅底取消选中态常驻描边，键盘焦点独立保留。
- 横向默认自然宽度，也可显式等分；More 继续使用原连续区间算法，极窄时滚动。页面明确设置宽度阈值后，左右纵向可转为顶部横向，保留同一 Root、当前分区和已挂载面板的草稿。
- 正式页面提供完整外观、方向、名称行数与横向宽度入口；设置场景使用双行和本页 560px 候选阈值。新增检查区按展开挂载，不改变公开示例或公共面板保留策略。

## 实测问题与回归关闭

| 问题 | 修复与证据 |
| --- | --- |
| 纵向长名称撑破列宽，省略号、指示线或焦点被裁切 | 去除 min-content 撑宽，限制内容预算；72 组布局逐项核对 Tab、Paint、Icon、Label、Count、Indicator 及焦点四边。 |
| 底板重复外围留白 | 统一为项目自身 3px 内缩，同步 More 的可用宽度计算；外侧 3px、相邻背景 8px 均实测。 |
| 数量被收缩或占用过多名称空间 | 普通数量不收缩，极长数量保留两字名称、图标及间距预算；MAX_SAFE_INTEGER 完整可访问说明与提示验证通过。 |
| 自动模式在空选择／禁用回显时因焦点恢复发出选择请求 | 恢复目标遵循已接受值；没有可聚焦当前项时返回导航容器，回归保持选择请求数为 0。 |
| 显式纵向 left／right 对齐带入横向 | 按实际方向计算，换向后的横向内容居中；选中与草稿保留。 |
| 原生滚动条覆盖首项指示线／焦点 | 纵向视口末端留出已有 12px Token，配对负外边距保持列宽与正文间距；真实 End→Home 滚动后[截图复核](native-scrollbar.jpg)。 |
| 短数量误触发全文提示 | 正式 IAB 中 `(0)` 宽度未溢出，但 scrollHeight／clientHeight 为 15／14px。自身高度比较仅用于 Label，Count 的横向省略与祖先裁切判断保留。原生页面同一度量下键盘聚焦后 Tooltip 为 0；长数量及双行名称正例继续通过。 |
| 新证据混入历史 B2 测试夹具 | 复制排除表补齐本轮精确文件清单；原失败 2 项关闭，该文件 232 项单独回归通过，冻结归档及负向断言保留。 |
