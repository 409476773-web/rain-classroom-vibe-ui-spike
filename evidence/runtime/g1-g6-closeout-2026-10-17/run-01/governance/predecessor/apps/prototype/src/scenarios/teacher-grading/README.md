## 历史过程

2026-09-16 用户授权生成高保真原型及业务所需局部改造。Prototype Mode / local-experiment；入口 `#teacher-grading`。

目标：让教师保持同一阅读视线完成查看作答、判断评分、输入反馈与连续批改。采用目录 / 答卷 / 评分三栏，白色阅读纸面配合浅冷色工作区。相比单栏逐步流程，减少反复打开与切换；相比在答卷上浮动评分，保留稳定的评分参考和操作位置。

范围：仅新增当前场景和原型入口。Rain UI Button、IconButton、Input、Textarea、Select、RadioGroup、Checkbox、Tag、SystemStatusTag、Avatar 直接消费；`teacher-grading-order` 是 Radio 局部组合配方，`teacher-grading-workbench` 是页面局部布局配方。无新增依赖，无公共组件修改。

来源：BM-C state.ts 的虚构试卷、groupSequence、scoreError；BM-B simulateTask 的取消与失败模拟。沿用卷别隔离、按题/按人遍历、草稿与正式评分分开、成功保存后才前进的状态合同。学生显示名为本页虚构。新画面不继承 BM-C 人工验收。

未验证假设：桌面教师以长时间连续阅卷为主；当前是纯文本作答，核心段重点标记仅教师可见；不模拟真实 PDF、手写笔、AI 或生产数据。刷新恢复初始数据，真实保存和学生端可见性未连接。

Token 与用途：页面浅底 Background/Neutral/2–3、白色面板 Background/Neutral/1；正文 Text/Neutral/1、辅助信息 Text/Neutral/3；当前选择与链接 Text/Brand/1 配 Fill/Brand/Alpha/4；品牌顶线 Background/Dark/1；分隔 Border/Neutral/3；重点标记 Fill/Orange/Alpha/2；失败 Text/Red/1。所有页面样式限定 `.tg`，无新基础颜色、字体或公共 token。UI 字体沿用 PingFang SC，字号/行高/间距/圆角沿用 Rain Token。

验证计划：原型应用类型与构建；浏览器覆盖快捷评分、常用评语、失败重试、草稿切换、卷别边界、分组切换、空结果恢复、专注模式、参考答案、概览返回；1440 / 1100 / 900 / 390 视口检查溢出与截图。自动检查和视觉人工验收独立记录。

## 2026-09-16 整页重构

用户明确要求使用 ui-ux-pro-max 搭配组件库重构整页。技能 SKILL.md 已读取；其 scripts/data 在安装目录中为损坏的路径占位文本，无法运行 design-system 检索。按技能的可访问性、优先任务、布局响应式、文本可读性规则执行；不引入其通用色板、字体或另一套设计系统。

设计选择：保留教师连续批改的三栏结构，压缩重复壳层；卷别/批改顺序/搜索/状态归目录，答卷去掉纸张套框、英文装饰标题和渲染层添加的公式，原样显示 mock 正文。右栏先得分、再可展开的评分细则、评语与常用反馈，保存操作固定。普通 Radio 和 Button 通过既有 local recipe 调整容器。评分 Input 使用已支持的 36px 尺寸；其他组件不改变公共实现。

交互修订：分数校验显示于字段，服务失败显示于底部并聚焦；重新编辑已评分对象以草稿提示；记住当前卷/顺序/父组上一次对象；切换作答重置阅读滚动；退出概览在保存期间禁用。保留零分、0.5 分、A/B 卷、父级遍历边界、失败保留和成功才前进。

范围仍为本目录；不修改公共资产、不新增依赖，不自动关闭视觉与颜色验收。亮色原型没有深色模式；真实读屏、物理触摸与生产保存未验证。
