# DatePicker 手动验证清单

这四组检查覆盖真实 Safari、触屏与软键盘、VoiceOver 实际播报和浏览器原生缩放。每组全部通过后，才能关闭对应检查；本地测试和窄屏模拟不能代替它们。

2026-10-13 用户报告：“Safari 浅色/深色全部通过；缩放只完成 200%”。Safari 的 S1–S4 登记为两种主题均通过；Z1 登记为用户已完成 200% 检查，缩放的主题结果未分项报告。真实触屏、VoiceOver、400% 和恢复 100% 仍待验证。设备、系统和浏览器版本未提供，不作推测，见[本轮反馈记录](final-confirmation/manual-acceptance.json)。

## 开始前

在电脑上打开 [DatePicker 预览](http://127.0.0.1:5395/#date-picker)。使用本轮版本，记录设备、系统和浏览器版本。分别检查浅色与深色，先保持默认密度和 100% 页面缩放。

主要样例是“截止日期”“截止时间”“日期区间”和“活动时间段”。点击“跨午夜”加载样例，记下字段原值。下面用 D 表示测试当天之后的一天，跨午夜测试值为 D 日 23:00 到 D+1 日 01:00，预期 2 小时。使用未来日期可避免当前时间限制干扰。

手机需要能访问的同版本预览地址；手机上的 `127.0.0.1` 指手机自身。如果尚未准备设备可访问地址，触屏组记为“环境待准备”。仅操作页面中的本地样例。

## Safari

使用实际安装的 macOS Safari。需要遍历所有按钮时，检查系统的键盘导航设置，以及 Safari 高级设置中的“按 Tab 键高亮显示网页上的每一项”；也可以按现有设置使用 Option+Tab。快捷键和菜单文字以当前版本为准。[Apple Safari 键盘说明](https://support.apple.com/guide/safari/keyboard-shortcuts-and-gestures-cpsh003/mac)

| 完成 | 操作步骤 | 通过标准 |
| --- | --- | --- |
| [x] S1 打开与日历导航 | 用 Tab 聚焦“截止日期”，按 Enter 或空格打开。使用方向键移动日期，按 Enter 选择。再检查“日期区间”的两点选择与翻月。 | 可用日期可选、禁用日期不能提交；焦点清晰且没有被裁切。宽屏纯日期范围显示双月，窄屏单月；带时间显示单月。 |
| [x] S2 时间与错误 | 打开“活动时间段”，把结束时间改为 `24:00`，按 Tab 离开输入框。再改回合法 `01:00`。在合法时间上试上下方向键。 | 无效时出现具体错误、确定不可用；改正后恢复。每个端点仅一个 HH:mm 输入，上下键每次调整 1 分钟，不越过 00:00 或 23:59。 |
| [x] S3 草稿与确认 | 改结束时间后分别试“取消”、Escape 和点击面板外；重开确认原值。再改成有效值，点“确定”。另做“清空→取消”，在非必填样例做“清空→确定”。 | 未确认修改不改变入口值；取消清空可恢复。确定后入口值才更新；非必填可确认空值，必填不能确认空值。取消、确定和 Escape 返回入口焦点；外点保留外部目标焦点。 |
| [x] S4 嵌套层与输入法 | 在“对话框设置日期”内打开 DatePicker，再打开月份菜单，逐次按 Escape。用当前中文输入法编辑日期或时间。 | 第一次只关月份菜单，下一次关日期面板，外层任务仍在。输入法组合期间不抢焦点、不误跳月、不提前确认；完成输入后正常校验。 |

## 真实触屏与软键盘

使用实际目标手机或平板，至少在 iPhone 或 iPad Safari 完成一轮；如果 Android 属于目标环境，再在 Android 实机补一轮。浏览器的手机尺寸模拟不计入本组。

| 完成 | 操作步骤 | 通过标准 |
| --- | --- | --- |
| [ ] T1 触屏面板与点按 | 用手指打开四类样例，点日期、翻月、切换开始或结束端点、展开时长，并点击四个分钟预设。 | 真实粗指针设备使用底部 Sheet，单月日历。能稳定点中，端点不串改，不依赖 hover；本库 Sheet 中日期、导航、时长和底部操作保持至少 44px 的目标高度。这是本库触屏合同，不是所有桌面按钮的统一标准。 |
| [ ] T2 软键盘与滚动 | 点开始、结束和自定义时长输入，保持软键盘打开；滚到错误说明和底部操作，再收起键盘。 | 当前输入可见，内容可滚动；能通过滚动或收起键盘触达取消、确定，没有永久被键盘遮住的操作。键盘收起后无空白残留、跳位或误提交。 |
| [ ] T3 转向与关闭 | 输入一半时切换横屏，再回竖屏。分别试取消、点遮罩关闭，再重开。 | 草稿在转向时不丢失、不乱序；面板保持可操作。关闭放弃草稿，重开恢复已确认值；页面滚动状态正常。 |
| [ ] T4 跨午夜与清空 | 设置 D 日 23:00 到 D+1 日 01:00，点确定。重开并清空，再取消；最后测试合法时长预设。 | 入口值和摘要表达准确的两天及 2 小时；清空取消恢复原值。预设只在点击时计算一次，后续修改起点不会偷偷锁定或重算结束时间。 |

## VoiceOver

在 macOS Safari 开启 VoiceOver，使用实际语音完成操作。默认 VO 键是 Control+Option，也可按当前设置使用 Caps Lock；用 VO+左右箭头浏览、VO+空格激活，需要进入组时用 VO+Shift+下箭头。iPhone 或 iPad 可另用左右轻扫和双击完成同样流程。[Apple VoiceOver 交互说明](https://support.apple.com/guide/voiceover/interaction-commands-cpvokys07/mac)

| 完成 | 操作步骤 | 通过标准 |
| --- | --- | --- |
| [ ] V1 名称与范围 | 依次读“截止日期”和“活动时间段”入口并打开面板；导航至开始日期、开始时间、结束日期、结束时间和两个日历按钮。 | 能听到字段名称、当前确认值和面板用途；开始与结束、日期与时间明确不同。没有只有“按钮”或相同名称却无法区分的关键操作。 |
| [ ] V2 日历与端点 | 导航日历日期，包含今天、选中日和禁用日；选择可用日期，切换日历按钮编辑结束端点。 | 能判断完整日期及选中、禁用等实际状态，知道正在改哪个端点；无需视觉猜测；禁用日不会提交。 |
| [ ] V3 错误与恢复 | 结束时间输入 `24:00` 后移出输入框，听取错误；重新回到该字段。改正后展开时长，清空开始值，听取不能使用时长的原因。 | 错误与具体输入关联，能够听到有效小时/分钟范围；确定不可用。修正后错误清除。缺少起点的原因可获取，无无关重复播报或无止境重复。 |
| [ ] V4 提交与焦点 | 修改有效值并确定；再开面板改值后取消。最后在外层对话框重复打开、关闭。 | 更新后的入口值可读取；取消保留原值，返回正确入口。不会把焦点丢到页面顶部或困在已关闭层中；嵌套关闭顺序正确。 |

## 浏览器原生缩放

用浏览器菜单的页面缩放，或 macOS 的 Command+加号/减号。分别验证 200% 和 400%；在 100% 时使用约 1280px 内容宽的桌面窗口，400% 时相当于约 320px 内容宽。CSS `zoom`、手机尺寸模拟、系统放大镜或捏合放大不能替代本组的原生页面缩放。Safari 某版本若不提供 400%，记录版本与上限，并在支持 400% 的目标浏览器补齐该项。[Apple Safari 缩放操作](https://support.apple.com/guide/safari/keyboard-shortcuts-and-gestures-cpsh003/mac)

| 完成 | 操作步骤 | 通过标准 |
| --- | --- | --- |
| [x] Z1 200% 文字与表单 | 调至 200%，打开四类样例；编辑起止值，展开时长，触发并修正无效时间。用 Tab/Shift+Tab 遍历。 | 标签、提示、值和按钮文字完整可读，不重叠、不截断；焦点可见，操作功能不丢失。允许合理换行和垂直滚动。[W3C 文字缩放标准](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html) |
| [ ] Z2 400% 重排 | 调至 400%，打开活动时间段和纯日期范围，滚动面板内容，找到取消、确定并完成一次编辑。 | 面板正文和操作无需双向来回滚动才能使用；不存在右侧关键控件被切掉、焦点被底部操作遮住或按钮不可达。双月收为单月、时长按钮换行是预期行为。[W3C 重排标准](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) |
| [ ] Z3 恢复 100% | 改回 100%，关闭并重开面板，检查数值和页面滚动。 | 已确认值不丢失，面板位置与滚动恢复正常，没有残留遮罩、错误尺寸或重复层。 |
