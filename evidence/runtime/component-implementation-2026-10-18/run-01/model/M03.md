## 输入、原因和改动

相近的 tab 外观可能承担页面地址、内容面板、业务范围、当前对象、字段条件或工具按下状态。名称检索不能代替这些真实职责；共享 CSS 不代表共享状态行为。

仅以下16份 Manifest 增加可选 discovery 或明确误文案：navigation-list、segmented-control、alert、native-select、tabs、navigation-tabs、navigation-bar、scope-navigation、object-navigator、radio、radio-group、toggle、toggle-group、sidebar、breadcrumb、recipe-input-group。`scripts/asset-discovery-pilot.test.ts` 验证跨来源真实关系和无虚构入口。Workspace 与 ConnectedSurface 的 Manifest / 公共代码未由本子任务修改。

31条关系已经逐条核对实际源码并通过引用检查，关键边为：

- NavigationTabsRoot 真正渲染 Tabs.Root；NavigationTabs.Nav/Panels 直接指向 Tabs 成员。
- NavigationBar 使用真实链接，复用导航范围内 Tabs class 表达外观，没有被声明成 Tabs wrapper。
- SegmentedControl 真正渲染 RadioGroup，并复用未从公共 UI 根导出的 RadioControl 行为缝隙。
- ScopeNavigation 组合 NavigationTabs、Popover、SearchInput；sharedContent 保持共享编辑实例，内部 `content: null` 不等于没有内容区。
- RadioGroup 负责自身选择协议并默认渲染受控 Radio；ToggleGroup 的数组/可空 pressed 状态仍独立。
- ConnectedSurface 只作为宿主通过 renderSurface 选择组合的几何近邻，不伪造 UI 对 Layout 的代码依赖。

每项 stateOwner/controlScope 有具体边界。现有 teacher-grading 的按题/按人及 A/B 卷真实 Tabs 面板被明确保留，草稿和评分仍由页面管理；不重开已接受方向。
