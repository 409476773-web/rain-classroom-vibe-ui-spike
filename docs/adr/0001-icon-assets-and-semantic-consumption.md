# ADR 0001：图标资产、语义与宿主颜色

日期：2026-09-03。状态：本地实施；Human Gate 单独记录。

## 问题与决策

AI 只看名称容易把形状近似、用途不同的图标混用。SVG 中写死前景色会使一级按钮中的图标无法反白；只把 SVG 文件复制过来，也不会把用户确认的场景默认传达给新任务。

采用三个独立层次：Figma 来源身份与未经改写的导出；框架无关的场景规则；React 图形消费。Figma「02 · Icons」为本批完整来源，42 项讨论身份只限定已确认语义范围。固定名称与组件来源保持一一对应，`edit` 与 `edit-pencil` 等旧新资产不自动合并。

`semantic-rules.json` 是语义唯一编辑源。生成器据此输出 TypeScript 查询数据与 AI 文档，目录页复用同一查询合同。查询先按实际动作、对象和组件场景判断；中文关键词只辅助检索，不作为运行时文案猜测器。来源未确认的用途可以由任务局部选择，不自动登记为全局默认。

## 渲染与颜色

普通图标使用外部 SVG 的 **alpha mask**，宿主 `currentColor` 提供前景色。源 SVG 字节保留，不批量替换 fill/stroke，也不把 luminance mask 内的白色改为按钮颜色。每次图形在独立图像文档中解码，源内部 ID 不进入页面 DOM；相同图标重复出现也不会争用渐变或蒙版 ID。

固有配色资产使用原始图像内容。分类需要源描述、变量绑定和可见绘制结构的依据；蒙版数量、蓝色、名称带 color 都不能单独构成推断。无法可靠分析的绘制结构进入显式复核，不自动改色。原始配色的品牌、文件类型和多色资产保留来源色值。

`button-loading` 的源 SVG 含角向渐变的 foreignObject。在浏览器外部 SVG 图像中的兼容性不可靠，因此使用同一节点直接导出的透明 PNG 作为 alpha mask，保留渐隐与宿主供色。动画、loading 替换和禁用状态继续由 Button 管理，Icon 不重复加动画或透明度。Button 也引用本次标准画布 PNG；其 24px 画布内可见环为 20px，宿主使用 120% mask-size 保持旧紧裁切图的可见尺寸，保留原 Button 布局与动画。旧 PNG 仅作为既有来源历史保留，无运行消费者。

默认尺寸为 1em；Button 的图标插槽管理自身尺寸，独立预览可明确指定尺寸。默认装饰图标隐藏于无障碍树，独立传达信息时传 `label`；交互和焦点由真实按钮/链接负责。

## 按需消费与安装边界

静态页面从 `@rain-next/ui/icons/<slug>` 引用命名组件。每个入口仅关联共享 renderer 和该图形。完整图形目录单独用于图库浏览，Foundation 目录只有元数据，不反向依赖 UI 运行时。

`registry/icons.json` 描述本地源码、共享文件、React 和样式依赖；它不是已发布的 shadcn 服务或 npm 包。消费依赖现有 workspace 和两个样式入口。构建一个实际单图标消费者并检查产物模块图，验证没有带入完整图库。

## 来源异常与验证边界

完整库存保留每个来源身份。源节点没有可见内容时登记 `source-unavailable`、原始错误和透明 PNG 证据，不生成可用导入，不以别的图形补位。目录显示待修复状态。可用资产数、完整身份数、语义确认范围和 Human Gate 分别报告。

生成一致性、文件闭合、导出来源、原始哈希、按需打包、页面消费、颜色与尺寸、键盘/无障碍、全库解码以及独立新上下文选型分别验证。自动检查通过不代表用户已经验收，也不代表来源异常已经修复。实际结果见 `evidence/runtime/icon-migration/verification.md`。
