# 决定：以可组合 Parts 接入单元格直接编辑规范

状态：本地共享实现；来源设计经用户审核，提炼后的整合界面待复核；未发布。

用户明确授权把2026-10-23已制定的视觉、交互规则与组件整理并加入库及Playground。现有Table支持多种数据模式，不能把一页课堂任务的字段、选择范围和保存流程固化为所有表格默认。

决定：在既有ui-table内公开动作单元格、行首操作、表格Checkbox、无内框输入、只读和内容Parts；通过Table.interaction="cell"显式启用单元格hover视觉，保持旧Table默认。Table Pattern组合既有Popover与Drawer，宿主继续持有权限、编辑/选择/保存与媒体集合。评审稿和Table Playground直接消费同一实现；目录维持一个Table入口。

收益：审核规则成为可引用合同与真实导出，减少页面重复CSS；字段操作与行选择不会串联。代价：宿主仍需接入状态和业务回调。限制：本批不替换连续录入/矩形范围/Canvas引擎，不推断真实上传与跨页选择规则，不改变旧资产或生产/发布Gate。当前合同见docs/ai/table-cell-actions.md，计划与验证单独记录。
