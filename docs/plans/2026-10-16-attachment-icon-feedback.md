# Attachment 格式图标反馈

用户要求应用库内已有的各格式彩色图标，并减小每个附件开头的图标。本轮在已授权的附件视觉优化范围内执行局部 System Mode 修正，仍是未发布候选。

- 依据：用户截图、正式图标选择规范、可用目录、Rain Designer v0.5 局部视觉/大小/组合检查。正式 `file-format-*` 资产保持其 intrinsic 配色，不重绘或改色。
- 改动：文件图标按具体扩展名静态匹配；没有专用图标时回退到受支持的 MIME/通用图标。图标 32px → 24px，图标区域 40px → 32px。真实图片缩略图、操作命中区和状态位保持原大小。旧五态/尺寸示例的 PDF 使用正式彩色 PDF 图标。
- 图标选择仅服务展示，不改变 `getAttachmentKind`、预览允许范围、文件选择约束或共享数据合同。别名属于本 Recipe 局部映射，不升级全库图标语义规则。
- 验证：代表格式、无类型、大小写、未知扩展名及原型属性名的匹配测试；现有 List/状态/宿主回归；相关类型与构建；独立测试页检查两表面、亮暗、360px 和真实图像回退。
- 来源：追加 `attachment-visual-2026-10-16/feedback-01` 基线、来源绑定与验证记录，保留前轮证据。当前运行视觉仍待用户审阅。

已知资产边界：Markdown 正式源图自带白底，保持冻结来源；没有 JSON 专用图标，不能用 JSONL 冒充。Numbers/Pages 与旧 Office 扩展名如采用别名，会在映射处明确记录。
