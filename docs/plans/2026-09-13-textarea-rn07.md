## 最小合同

- Textarea 采用原生 textarea，根与 control 两个 Parts；开放原生属性、ref、value/defaultValue、onChange/onValueChange、rows（默认 4）、appearance、status。
- 接入现有 FormItem：字段 ID 和状态优先；label / help / message 关联并去重；required / disabled 叠加；error 强制 aria-invalid。
- 原生控件拥有非受控值；受控值由宿主拥有。Enter 换行，IME 事件透传；maxLength 使用原生 UTF-16 计数语义，区别于 Input 的自定义字素计数。没有新增计数、清空、自动高度或表单引擎。
- 复用 fieldFrameRecipe、Input control reset、FormItem 颜色及 Focus；长文本使用现有 Reading/Small 14/24、12px 横向留白与 8px 纵向留白。纵向原生拖拽，禁用时不可拖拽；密度继承但不压缩长文排版。
- 课程说明样例：宿主拥有草稿、已保存值、校验、保存结果；模拟保存成功后提交，失败保留草稿，取消恢复已保存内容。Mock 数据与本地保存范围可见。

修改 Textarea 源码/公共导出、FormItem 的 ID 合并辅助与说明、样例路由和入口、Manifest/本地 Registry、精确扫描范围、阶段记录及本文件。不新增依赖或公共 Token。

未验证假设：原生多行编辑足以覆盖首个长文本场景；rows 和纵向拖拽满足当前高度需求。真实系统 IME、屏幕阅读器、物理触屏、全浏览器、人工视觉和对比度接受保持独立待办。共享字段原有颜色 finding 不因复用而关闭。
