# Carousel 公共实现视觉回正

用户反馈：感觉与视觉确认稿（尤其是按钮、指示条摆放方式）有差异。延续已授权的公共升级，以只读、已接受的carousel-study v0.4为基准。

工作模式：System Mode。只修改Carousel公共控件和五个页面局部示例及对应合同；不修改已接受原型、运动引擎、Drawer/Conversation实现或其证据。

已复现：独立布局箭头从标题右侧移到下方，左右短条没有围绕轨道；播放入口从36px高、带16px图标和暂停/继续文字的圆角矩形变为36px圆形图标；覆盖箭头缺少原8%轻阴影；纵向下箭头和底部短条偏移为16/12px，原稿为32/28px。

修正：示例在标题右侧或连续展示页脚组合公开导航；独立短条按四向包围轨道。公共PlaybackControl默认保留可见文字，showLabel=false仍可用紧凑图标形式。恢复覆盖阴影和纵向偏移，保持已确认的4px短条、6px间距及15px胶囊端距。

媒体锚点补充：窄屏纵向左侧胶囊应在192px插画的96px中线，不进入文字；窄屏水平居中箭头内距12px。连续卡片原稿实际宽288px/间距20px，旧公共Item的288px包含16pxpadding，实际仅272px，连带改变按钮所依赖的封面高度。按原稿恢复实际宽度、间距、纵向可见高度及卡片/封面标签的留白，仍只由Embla维护运动。

验证：先记录浏览器差异并使可见播放文字回归失败，再实现；对照原稿量测独立/覆盖、四向短条、横纵及390px/1280px；复核播放与导航，运行Carousel相关测试、类型和构建。原公共升级封存证据不重签，视觉反馈另存有限来源与颜色记录。后继旧治理可能拒绝新反馈字节，保留其边界，不把它改为全G6通过。

限定复核发现默认带文字的播放按钮在aria-disabled=true时仍执行宿主点击与播放；布尔true和字符串true两项回归先失败，再由共享处理器在回调前阻挡，修复后通过。其它本轮布局、导航、焦点与观察器清理未发现需阻断P1/P2。

未验证：人工视觉验收、Safari/VoiceOver、真实触摸、覆盖媒体对比度、发布与生产接入。
