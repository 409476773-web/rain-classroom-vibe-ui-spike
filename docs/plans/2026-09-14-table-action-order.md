# 资料表格操作行顺序

2026-09-14，用户截图反馈：刷新资料/显示列居左，重要批量操作居最右；取消选择置于发布按钮左侧，仅有选中资料时显示。Prototype Mode，仅调整既有本地资料配方。

实施：复用两组 Inline，左组刷新/显示列，右组已选数量/条件显示的取消选择/标为已发布；右组自动左外距并右对齐，窄屏允许自然换行，但取消/发布作为一组保持同排，确保取消始终位于发布左侧。原发布按钮无选中时禁用、刷新和清空筛选行为不变。公共组件和 Token 不改。

验证：扩展现有选择/分页单元验证取消按钮显隐及清除行为；浏览器核对操作顺序、左右边界、浅深主题/两种密度以及320px换行。运行相关类型及治理检查。新布局视觉待用户确认。

实施完成。4项资料配方单元、15项三浏览器Table场景及最终窄屏组合的3项定向复跑通过，类型/治理检查通过。[验证记录](../../evidence/runtime/table-action-order/verification.md)。
