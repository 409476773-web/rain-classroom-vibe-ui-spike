# 教学任务中的图标与阅读配方

这是本地消费指南，沿用[已确认图标语义](icon-selection.md)与[排版合同](../../packages/foundations/src/typography-contract.ts)。不新增图标，不改变现有58项语义确认，不把未确认用途写成资源不可用。

## 先分清动作、对象与状态

| 教学意图 | 本地选择及理由 | 避免混淆 |
| --- | --- | --- |
| 查询教学资源 | `SearchIcon`，`@rain-next/ui/icons/search`，与“查询”文本同一按钮；这是已有 search 规则。C01 筛选工具栏已使用 | 查询动作不以 file 图形替代；图标不决定即时或提交生效 |
| 批改与调整得分 | 保存按钮保留“保存并继续/保存评分”文字；若另设“修改评语”动作，已确认 edit 对应 `EditPencilIcon` | pencil 只表示编辑，不等于“已批改”；不把正确与已保存混为同一业务状态 |
| 讲解与答案解析 | 当前组合保留明确文字标题，长解析用 reading-default；需要独立讲解图标时先查实际对象和资源目录，记录任务局部选择 | 没有全局唯一“讲解”规则，不从“消息”形状推断正在讲授或AI回答 |
| 作业对象 | 保留完整作业名称；附件按实际格式使用已有 file-format 资源，泛文件对象可查 `FileIcon` | 文件类型不是作业发布状态，文件图标不自动代表可下载或可提交 |
| 课堂互动 | 点赞、鼓掌、收藏按已确认 intent/context 查询；动作旁保留具体名称 | 鼓掌不是“答对”，点赞不是“已收齐”，不能用图形替代业务统计含义 |
| 资源引用 | “查看来源”“打开附件”明确目标及打开方式；需要链接图形可局部选 `LinkIcon`，先核可用入口 | 链接、引用、分享、下载不是同义动作；不把 link 资产的可导入性当成全局语义确认 |
| 保存/请求状态 | C01 使用“保存失败，已保留输入”“已保存”等可读文字和 status/alert；若加图标，成功可按 success 用 circle-check、错误按 failure 用 circle-close | 状态不只靠红绿；成功不等于评分正确，失败不清空输入；不为每状态新画SVG |

装饰图标设置 `aria-hidden`，完整文字承担名称。只有在已有名字且任务适合时使用 IconButton，并使用其完整命中区与 aria-label，不把裸 SVG 作为按钮。当前查询图标与文字共享 Button 的尺寸、禁用、焦点和点击，不引入第二个操作点。同页相同动作使用同一规则；语义不确定时记录范围，不晋升全局默认。

## 阅读关系先于字号

C01 的分区标题是16px、600，按 heading-section 的24px行高；字段标签与操作沿 UI 控件合同。长说明、评语用阅读预设，短提示用已有 supporting/caption 角色，必要内容不能为了显得轻而改成装饰或不可读浅色。当前仓库已有9–40字号合同与具体角色约束，不能套用旧记忆的“一律禁用某字号”。字体仅使用随包授权资源和宿主回退。

- 筛选：条件、查询与结果分开；32px字段与small按钮明确配对。多个标签、长中文或窄屏允许换行，输入框的长值可以原生横向滚动查看，不压小字号。
- 分区表单：字段组2列在空间不足时折为1列；Textarea保留多行、就近错误与帮助。名称和课程是对象信息，满分与说明是评分要求，保存属于整表。
- 连续批改：学生与题目为标题；满分、得分、评语、草稿状态、动作顺序稳定。进度1/2和0分都显示文字；普通字段不套用28px关键数据样式。长评语完整保留，切换对象的身份与显示序号分开。
- 只在需要纵向比较数值时使用 `tabular-nums lining-nums`；不同长度的中文与数字共存时核对截断、换行与行高，不能靠固定高容器隐藏内容。

实际入口 `#compositions` 有1440/390、失败/等待/禁用和长文本记录；CSS zoom 200%只代表局部重排探测，不能冒充原生浏览器缩放、Safari、VoiceOver或真实触摸验收。对比度结论见[局部消费矩阵](consumption-contrast.md)，Human Gate仍独立。
