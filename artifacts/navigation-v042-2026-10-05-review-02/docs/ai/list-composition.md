## 保持的关系

1. 白色页头容纳标题、当前结果数量与课程上下文；总数只在此处显示，底部分页通过 showTotal=false 隐去重复总数并靠右排列。查询区和结果区共用左右对齐线。
2. 宽屏查询与显示工具同排；中等窗口明确分为完整查询行和右对齐工具行。批量操作随选择出现，发布或取消后焦点返回本页全选。
3. 表格名称单行省略，保留完整可访问名称、悬停提示和资料信息入口；课程归属占固定次行。宽屏按列比例分配，中等窗口保留其他属性的必要宽度，剩余空间归名称。卡片名称最多两行，不强制预留空行；类型/课程/只读合并，日期与状态保持同一底部位置。
4. 查询控件使用完整 36px 方案；页面/标题 14/16px，表格正文/表头 14px，主要靠字重区分。Tag 保留自身完整方案，不按页面强行缩放。
5. 同一个表格是一个白色任务表面；不对每行/每个字段再套 Card。切换为卡片时，每张卡片才代表独立对象。复选框位于独立选择列，控制整张卡片；背景及边框反馈整卡选中。名称只负责查看信息，切换视图沿用同一份对象选择状态。
6. 窄屏先换行查询区域，表格保持可读列宽并可键盘横向滚动；需要同时浏览完整对象时可切换卡片。

## 可调整与退出条件

| 内容变化 | 调整方式 | 检查 |
| --- | --- | --- |
| 增加一种筛选维度 | 放进查询组，宿主新增过滤条件 | 与搜索组合，改变条件清空选择/回首页 |
| 名称下增加课程归属 | 放在名称同一单元，辅助文字同档；只读提示共行 | 不与下一行对象混淆；完整名称能在资料信息中查看，行高不随名称长度跳动 |
| 字段减少或某列隐藏 | 重新分配剩余宽度，不按 DOM 序号猜列身份 | 名称仍有空间，日期/状态不被挤压 |
| 需要长时间编辑单个对象 | 转入表单/编辑工作区 | 不在列表中堆满编辑字段 |
| 需要按趋势定位问题 | 转入分析组合 | 不为了复用列表而删掉必要比较 |

上述数值只属于本例，不新增全库规范。先判断任务/内容，再决定复用什么。每次只需记下：参考的组合、适合原因、保留关系、必要改变；记录不进入业务页面。

## 状态与边界

宿主拥有数据、搜索草稿、过滤、排序、分页、ID 选择、加载锁与错误。搜索按钮/Enter 提交；过滤清空选择并回首页；翻页/排序/视图切换保留选择；只读项排除；当前页全选不代表全部结果；刷新失败保留内容，卸载后忽略迟到请求。原状态说明见 [BM-A](../../apps/prototype/src/scenarios/bm-a/state-contract.md)。

本例新增名称打开信息弹窗；不接入真实文件或持久化。迁移样例只是在同一局部 Fork 上增加类型过滤和课程归属，未证明不同页面家族的迁移能力。

提交前按整页 → 区域关系 → 模块 → 状态的顺序对照截图。优先修正任务重心、重复表达和空间比例，再调整局部字号/间距。实际结果与限制见 [本轮记录](../../evidence/runtime/list-composition/review.md)。

## 资料信息与操作边界

- 本页只展示资料元信息，名称入口标明“查看资料信息”，不冒充文件阅读。原型虚构说明保留在页面预览区。
- 弹层用 Header 内的 Inline 组织左标题、右关闭；按 Dialog 已有规范使用 CloseBold 28/20。正文为名称及属性列表；没有独立任务时不添加 Footer。
- 已删除重复的更多菜单与仅显示提示的“记录稍后处理”。需要真实对象操作时再按任务补充。
- 选择、查看、状态属性互相独立；不要把复选框与日期放成一组，也不要让标题点击切换选择。
- 第三轮本地交互/构建通过；仓库级 Tailwind B2 检查存在本轮范围外报错，详见 review.md。视觉待用户复核，不作为成熟生成样板。
