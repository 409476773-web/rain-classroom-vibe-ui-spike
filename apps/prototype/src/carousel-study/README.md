# Carousel 视觉与动效对照稿

2026-10-14 · Prototype Mode · local-experiment · v0.4 当前对照稿视觉与交互已获用户确认。

用户在调研与设计规格 v0.2 后指示“继续下一步”，本轮形成可操作的视觉与动效对照稿。不修改公共 Carousel、现有 Playground、依赖、Registry 或公共资产验收状态。

依据：仓库 AGENTS、SPIKE_BRIEF 品牌约束、G6 当前合同、Rain Designer v0.2.1 / 设计指南 v0.5、prototype-design 与图标规范；根工作区 evidence/carousel-research-2026-10-14 中的实测及三张用户参考图。

目标：让精选内容、课程多卡、纵向内容和连续展示可直接体验；控制器共享位置；短条可点击；定时与连续具有不同节奏；取消外置箭头占用的窄屏通道。

局部选择：沿用 Rain Token、PingFang SC 和正式可用图标。精选/课程/纵向复用现有 Carousel 的公开 API；连续展示使用页面私有原生滚动轨道与按经过时间推进的动画，不调用 Embla 私有引擎。内容及原创几何插画为演示材料，详细内容为本地预览。

范围：独立 carousel-study.html、src/carousel-study 目录、专用构建配置，以及本轮浏览器证据。保留其他未提交工作。

验证方法：原型类型检查、此 HTML 的专用构建；桌面与390px浏览器查看；箭头/短条/纵向/拖动；定时与连续的暂停、手动接管、恢复；页面溢出、边界焦点。浏览器实测结论稍后记录，未执行项不标通过。

假设：课程数据仅用来评议构图；动效速度和停留时间是首稿值；公共插件与最终API不在本轮确定。没有因此获得全组件验收、生产接入或发布授权。

## v0.4 控件反馈（2026-10-14）

用户要求箭头更轻、更淡、使用中性色，并补充 Apple/Mantine/Ant Design 截图中的覆盖式布局。本轮增加覆盖内容/与内容分离两种布局，覆盖控件在稳定层，封面和文字区分配各自空间；所有导航与播放控件采用具名 Local Recipe 的中性灰状态。原有业务 CTA 保留品牌色。公共组件、Token 与依赖不改。

16:33 追加：短条厚度3→4px、可见间距统一6px、当前态改浅灰；16:38追加：覆盖胶囊内两端可见留白7→15px，竖向同步。短条点击目标保持至少24×32px（竖向32×24px）。当前条28px、其他18px；均为页面局部探索值。

覆盖层不接收空白区域指针事件，按钮独立接收；禁用保留焦点。连续展示布局变化保留相对滚动位置，箭头与拖动同步位置；纵向连续箭头放在插画列，避免挡住文字。

最新反馈、修改前源码与检查：根工作区 evidence/carousel-research-2026-10-14/prototype/feedback-01。本轮用户确认及其范围见下节；全组件无障碍与发布验收保持独立。
